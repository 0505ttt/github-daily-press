JustVugg/colibri

纯 C 零依赖的端侧 MoE 推理引擎：消费级硬件跑 744B~2.8T 前沿模型
⭐ 总计 33,770 今日 +2,035 C
详细介绍

解决「前沿 MoE 大模型只有数据中心跑得动」的问题：每个模型就是一个 C 文件，零引擎依赖。核心思路是把 VRAM、内存、硬盘当成一整层推理内存层级——稠密部分（注意力、共享专家、嵌入，约 17B 参数）常驻内存，19,456 个路由专家按需从 SSD 流式读取，靠 LRU 缓存和 OS 页缓存加速，25GB 内存的机器就能跑 744B 模型。已支持 GLM-5.2/5.3、Kimi K3（2.8T）、DeepSeek V4 Flash、Qwen3.8-Flash-Next 等九个模型家族。技术亮点包括 MLA 权重吸收、原生 MTP 多 token 投机解码、int4/int8 整数点积内核。与 llama.cpp 等通用框架不同，它是专门针对 MoE 专家流式加载的激进研究平台，昨天 #1 今天 #2，连续第二天上榜。

适用领域

想在个人电脑/工作站本地跑前沿开源大模型的开发者；推理优化与系统方向的研究者；不想付 API 费用、不想被云厂商绑定的「大模型平民化」用户。

📚 知识归类：A-AI/机器学习 › LLM推理框架 › 端侧MoE推理

⭐ 总计 4,592 今日 +102 Rust
详细介绍

定位是「Agent 时代的 source control」：每次 Agent 运行都产生 checkpoint，commit 被关联回产生它的会话——提示词、工具调用、推理过程、文件变更全部绑在一起，几个月后仍然可以查询「哪个 Agent 在哪个 prompt 下改了这行代码」。Claude Code、Codex、Atlas 内置 Agent 以及 ACP 注册表里的任意 Agent 可以并排跑同一个代码库，共享一份记忆：Claude Code 做过的决定会自动出现在 Codex 的下一个 prompt 里，中途换 Agent 不用从头再来。你的 Markdown 笔记（.atlas/knowledge/、CLAUDE.md、AGENTS.md）会作为上下文喂给所有 Agent。本地优先（代码、笔记、会话留在本机），Tauri 构建，目前官方支持 macOS。

适用领域

MG1937/ASC

超快 Android 反编译器前端：352MB APK 全局交叉引用搜索只要 1.79 秒
⭐ 总计 1,140 今日 +122 Python
详细介绍

BlackHat Europe Arsenal 议题项目，核心思想是反传统而行：传统反编译器要吃掉数 GB 内存、花几十分钟构建全局索引，而 ASC 直接把编译产物当成只读数据库按需查询——在 Deflate 比特流内部直接探测、构建密集 Huffman 查找表提取元数据，不碰无关数据块；再利用 R8 编译器确定性常量重排与指令去重留下的高密度物理布局，做跨 DEX 闪电搜索；配合 O(1) 指令定位原语实现常数时间方法解析，无需构建重映射表。命中目标后只抽取该类的字节码及其依赖，在内存中动态重建一个最小自洽 DEX 立即反编译。实测 352MB 商业 APK：全局交叉引用 1.79 秒、反编译目标类 177 毫秒、仅占 141MB 内存。pip install droidasc 即可用。

适用领域

Android 安全研究与大规模 APK 审计；移动逆向工程师快速定位目标类；为 Agent/自动化分析提供毫秒级反编译原语。

📚 知识归类：G-安全 › 逆向工程 › Android按需反编译
