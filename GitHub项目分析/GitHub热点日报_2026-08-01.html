🎯 适用领域： 逆向工程师、安全研究员、渗透测试人员、CTF 选手、使用 Claude Code / Kiro / Cursor / Cline 等 AI 编程客户端的安全从业者。

C++ ⭐ 总计 4,965 今日 +161 🍴 Fork 403
硬件黑客的瑞士军刀——ESP32 版 Bus Pirate，一个设备通杀 20+ 种协议
📋 详细介绍： ESP32 Bit Pirate 是一款开源固件，灵感来自传奇的 Bus Pirate，可将 ESP32 设备变成多协议开发和分析工具。它支持嗅探、发送、脚本化以及与各种数字协议交互——I2C、SPI、UART、1-Wire、2-Wire、JTAG、CAN、I2S、USB 等，还能处理无线协议如蓝牙、Wi-Fi、Sub-GHz、RFID、RF24、FM 和蜂窝通信。提供 Web 串行 CLI 界面，可通过浏览器直接操作，无需安装额外软件。内置 LittleFS 文件系统支持脚本保存和自动化。与原版 Bus Pirate 相比，ESP32 版本的优势在于更强的处理能力、无线协议支持和 Web 界面的便捷性，且硬件成本极低。
