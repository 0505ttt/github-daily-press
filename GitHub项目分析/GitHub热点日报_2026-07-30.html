#1 opengeos/GeoLibre
轻量级、云原生的开源 GIS 平台——浏览器、桌面、移动端、Jupyter 全平台运行
TypeScript ⭐ 总计 3,992 🔥 今日 +667 🍴 Fork 430
📝 详细介绍
GeoLibre 是一款免费开源的轻量级 GIS（地理信息系统）平台，致力于在 Web 浏览器、桌面应用、移动端和 Jupyter Notebook 中统一运行，同时保持数据本地化与隐私。技术栈采用 Tauri v2 + React + TypeScript + MapLibre GL JS + DuckDB-WASM Spatial + deck.gl 构建，同一套代码可编译为原生桌面应用和 Android 应用。支持 3D Tiles 渲染、行星底图（地球、月球、火星等）、SQL 工作空间、700+ 免费 GIS 工具。与 QGIS 等桌面 GIS 相比，GeoLibre 强调零安装、跨平台和云端协作。
🎯 适用领域
地理数据分析师、GIS 研究人员、城市规划者、环境科学家；需要在浏览器中快速可视化和分析地理空间数据的团队；Jupyter Notebook 用户的地理数据工作流。
🏷️ 知识归类
C-前端/Web › GIS平台 › 云原生地理可视化
#2 moeru-ai/airi
自托管的 AI 虚拟伴侣——重现 Neuro-sama 的开源实现
TypeScript ⭐ 总计 45,348 🔥 今日 +676 🍴 Fork 4,483
📝 详细介绍
Project AIRI 旨在重现虚拟主播 Neuro-sama 的能力，打造一个可以自托管的 AI 虚拟伴侣。支持实时语音对话、VRM/Live2D 模型驱动、以及自主玩 Minecraft、Factorio、Kerbal Space Program 等游戏。技术栈大量使用 Web 技术（WebGPU、WebAudio、WebAssembly、WebSocket），桌面版可利用 NVIDIA CUDA 和 Apple Metal 进行原生加速。支持 30+ 种 LLM 提供商（OpenAI、Claude、DeepSeek、Qwen 等），跨 Web/macOS/Windows 平台运行。
🎯 适用领域
虚拟主播爱好者、AI 伴侣开发者、VTuber 技术研究者；需要自托管 AI 角色交互方案的个人；对 WebGPU/浏览器端 AI 推理感兴趣的前端开发者。

ECC（Everything Claude Code）是一个开源的 Agent Harness 性能优化系统，为 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot、Antigravity 等 AI 编程工具提供统一的技能、记忆、安全和研发流程框架。包含 261 个工作流技能、64 个专用子代理、覆盖 12+ 语言生态系统，横跨编码、研究、安全、媒体等场景。2.0 版本定位为「跨 Harness 操作系统」，可在不同 AI 编程助手间共享配置。该项目是 GitHub 上星标最高的 Agent 工具仓库之一。

#4 huggingface/speech-to-speech
Hugging Face 出品——用开源模型在本地构建语音对话 Agent
Python ⭐ 总计 7,819 🔥 今日 +837 🍴 Fork 999
📝 详细介绍
huggingface/speech-to-speech 是 Hugging Face 官方推出的本地语音 Agent 框架，支持用完全开源的模型构建端到端语音对话系统。集成语音识别（STT）、LLM 对话推理、语音合成（TTS）三大模块，用户可自由组合不同开源模型（如 Whisper、VAD、XTTS 等）构建低延迟的实时语音 Agent。支持本地服务器和云端提供商两种后端模式，无需依赖商业 API。与商业语音方案相比，它强调完全本地化、数据隐私和模型可替换性。

FaceSwap 是深度学习领域最具知名度的换脸开源项目，利用深度学习技术识别和替换图片/视频中的面孔。工作流程分为 Extract（提取）→ Train（训练）→ Convert（转换）→ GUI（可视化）四个核心阶段，每个环节都有独立工具支持。支持多种模型架构（如 Phaze-A、Villain 等），可在 CPU 或 GPU 上训练。项目强调伦理使用，内置使用规范和免责声明。拥有活跃的 Discord 社区、论坛（faceswap.dev）和详尽的文档。

#8 microsoft/VibeVoice
微软开源的前沿语音 AI——统一的语音合成（TTS）+ 语音识别（ASR）平台
Python ⭐ 总计 51,226 🔥 今日 +332 🍴 Fork 5,707
📝 详细介绍
VibeVoice 是微软开源的前沿语音 AI 项目，集成语音合成（TTS）和语音识别（ASR）两大核心能力。ASR 模块支持单次处理 60 分钟长音频，生成包含说话人、时间戳、内容的结构化转录，原生支持 50+ 种语言，已集成进 Hugging Face Transformers。最新的 VibeVoice-ASR-BitNet 通过异构量化将模型从 4.62GB 压缩到 1.58GB，在 3+ CPU 线程上实现实时推理（RTF < 1），无需 GPU。项目已集成到 Azure AI Foundry Labs。
🎯 适用领域
语音交互应用开发者、需要长音频转录的媒体/法务团队、多语言语音识别场景、边缘设备上的语音 AI 部署；微软 Azure 生态用户可直接在 Foundry Labs 中体验。
🏷️ 知识归类
A-AI/机器学习 › 语音技术 › 前沿语音AI（TTS+ASR）

TypeScript ⭐ 总计 17,842 🔥 今日 +58 🍴 Fork 1,851

OpenWork 是一个免费开源的桌面应用，专为共享 AI 工作流而设计，是 Claude Cowork 和 Codex 的开源替代方案。核心理念：只需添加一个 OpenWork MCP 到 Codex、Claude Code、Cursor 或其他兼容 Agent，就能在不同工具、团队成员、机器之间复用同一套技能、MCP 连接和服务。提供 search_capabilities 和 execute_capability 两个核心工具。团队版 OpenWork Den 提供推理资源管理、权限控制、技能市场发布等企业级功能。基于 opencode 构建，支持 50+ LLM 和自带 Key 模式。

#10 obra/superpowers
为编码 Agent 打造的完整软件开发方法论——可组合技能 + 自动化研发流程
Shell ⭐ 总计 263,235 🔥 今日 +686 🍴 Fork 23,507
📝 详细介绍
Superpowers 是一套完整的面向编码 Agent 的软件开发方法论，构建在一组可组合技能和初始指令之上，让 AI 编码助手自动遵循专业开发流程。核心流程：Agent 先与用户对齐需求，拆解出可消化的小块规格说明；设计确认后自动生成实现计划；用户说"go"后启动子代理驱动开发（subagent-driven-development），让多个 Agent 分别处理工程任务并互相审查。强调真正的红/绿 TDD、YAGNI 和 DRY 原则。Agent 可自主工作数小时而不偏离计划。支持 Claude Code、Codex、Cursor、Gemini CLI 等 11+ 平台。与 ECC 相比，Superpowers 更侧重方法论和流程自动化。
🎯 适用领域
重度使用 AI 编程工具的开发者和团队；希望让 AI Agent 遵循专业 TDD 流程的工程团队；追求 AI 自主开发效率最大化的个人开发者；需要跨多个 AI 编程平台共享开发方法论的组织。
🏷️ 知识归类
B-开发者工具 › Agent技能框架 › 软件开发方法论
