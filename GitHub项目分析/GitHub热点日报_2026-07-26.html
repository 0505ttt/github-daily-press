Swift ⭐ 总计 29,352 🔥 今日 +1,198

详细介绍

BitChat 是一款双传输层架构的去中心化消息应用：本地使用蓝牙低功耗（BLE）Mesh 网络实现离线通讯，互联网环境下通过 Nostr 协议实现全球通讯。无需账号、无需手机号、无需中央服务器，隐私优先设计。

蓝牙层采用 Noise 协议端到端加密并支持多跳中继（最多 7 跳）；Nostr 层使用 NIP-17 加密和 290+ 全球中继网络。支持基于 geohash 的地理频道（从街区到国家级别），三击紧急擦除所有数据，LZ4 消息压缩和自适应电池模式。原生支持 iOS 和 macOS，界面采用 IRC 风格命令（/slap、/msg、/who）。

适用领域

注重隐私的通讯用户、处于网络受限或断网环境的人群（抗议、灾区、偏远地区）、去中心化通讯技术爱好者、比特币/Nostr 生态开发者

为 AI Agent 打造的最快浏览器自动化工具——你浏览网页时 Agent 在并行工作
JavaScript ⭐ 总计 4,064 🔥 今日 +898

详细介绍

ego lite 是一款从零开始为"人与 AI Agent 共享"设计的浏览器。与 browser-use 等自动化框架不同，它本身就是浏览器——Agent 在自己的隔离 Space 中运行多个任务，而你的标签页始终不受干扰。

核心亮点：基于 JavaScript 函数调用而非 CLI 模式，复杂任务速度提升 2.5 倍且 Token 消耗更少；每个 Agent 拥有完全隔离的 Space（独立工作区）；通过 ego-browser 技能层桥接任何 Agent CLI（Claude Code、Codex、Cursor 等）；可迁移 Chrome 数据（登录态、Cookie、扩展）。目前在 macOS 上可用，Windows 和 Linux 在路线图中。

适用领域

使用 AI Agent 进行浏览器自动化的开发者、需要并行运行多个 Agent 任务的重度用户、注重隐私和效率的自动化工程师

Rust ⭐ 总计 12,671 🔥 今日 +1,705

详细介绍

Buzz 由 Block（原 Square）团队开发，是一个自托管的工作空间平台，核心设计理念是"Agent 是成员，不是机器人"——人与 AI Agent 共享同一频道、同一个事件日志。底层基于 Nostr 协议，每条消息、代码补丁、工作流步骤都以签名事件形式存储在同一审计链中，无论作者是人还是进程。

Agent 拥有独立的密钥对和身份，可以打开代码库、发送补丁、运行 CI、审查代码、编辑画布，享有与人类团队成员相同的能力表面。桌面端基于 Tauri + React，支持 macOS / Linux / Windows。提供 buzz-cli（Agent 优先的 JSON 接口）和 ACP 框架（支持 Goose/Codex/Claude Code）。

适用领域

需要深度集成 AI Agent 到日常开发协作流程的技术团队、追求统一审计轨迹的合规导向组织、自托管优先的隐私敏感型企业
