lyogavin / airllm

让 70B 大模型跑在单张 4GB 显卡上——极致显存优化的 LLM 推理引擎

⭐ 今日新增+963
总 Star25,595
语言Python

📖 详细介绍

AirLLM 通过层流式推理（layerwise streaming）技术，大幅降低大模型推理的显存占用，让 70B 参数模型在单张 4GB 显卡上运行——无需量化、蒸馏或剪枝。更夸张的是，405B 的 Llama 3.1 只需 8GB，DeepSeek-V3（671B）约 12GB，而 Kimi K3（2.8T）仅需不到 4GB，因为稀疏 MoE 模型每次只流式加载一个专家而非整层。核心原理是将模型层存储在磁盘/SSD 上，推理时逐层加载、逐层释放，以时间换空间，使超大模型在消费级硬件上成为可能。

🎯 适用领域

本地部署超大模型的开发者、GPU 显存有限但想跑大模型的个人研究者、需要离线推理超大模型的场景、教育/演示用途。适合 4-8GB 显存的笔记本/台式机跑 70B+ 级模型。

TencentCloud / TencentDB-Agent-Memory

AI Agent 的团队级记忆中枢——把对话、文档、代码变成可治理、可共享的记忆资产

⭐ 今日新增+604
总 Star10,923
语言TypeScript

📖 详细介绍

腾讯云出品的 Agent 记忆系统，核心架构基于两大支柱：记忆分层（Memory Layering）和符号化记忆（Symbolic Memory）。短期记忆用 Mermaid 符号图压缩冗长的工具日志，减少 Token 消耗最高达 61.38%；长期记忆构建语义金字塔：L0 对话 → L1 原子事实 → L2 场景块 → L3 人物画像。与把数据堆进向量数据库的传统方案不同，它强调"渐进式披露"——Agent 只关注顶层结构，需要细节时通过 node_id 下钻。已适配 OpenClaw 和 Hermes Agent 两大框架，本地零配置即用（SQLite + sqlite-vec 后端）。在 OpenClaw WideSearch 基准上，pass rate 提升 51.52%。

🎯 适用领域

AI Agent 开发者、需要给 Agent 加上持久记忆的团队、Agent 基础设施建设者、Hermes/OpenClaw 用户。场景：多会话记忆保留、用户画像建模、长程任务上下文压缩、跨 Agent 记忆共享。
