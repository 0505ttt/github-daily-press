#1 pascalorg/editor
基于 React Three Fiber 和 WebGPU 构建的浏览器端 3D 建筑编辑器
⭐ 18,620（+415 今日） TypeScript 🍴 2,523 Forks
📖 详细介绍
Pascal Editor 是一个完全在浏览器中运行的 3D 建筑设计工具，使用 React Three Fiber + WebGPU 实现 GPU 级渲染速度，即使五年前的笔记本也能流畅运行。采用 Turborepo monorepo 架构，分离为 core（场景状态）、viewer（3D 渲染运行时）、editor（编辑工具）、nodes（内置节点定义）四个包，职责清晰。支持楼层平面图绘制、门窗放置、区域标注等完整建筑设计流程，并通过 IndexedDB 持久化场景数据、Zundo 实现撤销/重做。与专业 3D 建模软件相比，它零安装、即开即用，数据完全本地化。
🎯 适用领域 建筑师、室内设计师、3D 建模爱好者；需要在浏览器中快速创建和分享建筑方案的用户；对 WebGPU/React Three Fiber 感兴趣的前端开发者。
C-前端/Web › 3D建筑编辑器 › WebGPU渲染

Jenkins 是 CI/CD 领域最经典的开源自动化服务器，历史悠久、生态庞大。通过丰富的插件体系支持几乎所有构建、部署、自动化流水线场景。今日上榜反映其在 DevOps 基础设施中的常青地位——尽管新一代 CI 工具（GitHub Actions 等）兴起，Jenkins 凭借自托管、极强的可扩展性仍被大量企业使用。Java 实现，可独立部署。
🎯 适用领域 企业 DevOps 团队、需要自托管 CI/CD 流水线的组织、传统软件交付流程。
E-基础设施/DevOps › CI/CD › 自动化服务器

自托管的 AI 虚拟伴侣——重现 Neuro-sama 的开源实现
⭐ 44,716（+796 今日） TypeScript 🍴 4,446 Forks
📖 详细介绍
Project AIRI 旨在重现虚拟主播 Neuro-sama 的能力，打造一个可以自托管的 AI 虚拟伴侣。它支持实时语音对话、VRM/Live2D 模型驱动、以及自主玩 Minecraft、Factorio、Kerbal Space Program 等游戏。技术栈大量使用 Web 技术（WebGPU、WebAudio、WebAssembly、WebSocket），桌面版可利用 NVIDIA CUDA 和 Apple Metal 进行原生加速。支持 30+ 种 LLM 提供商（OpenAI、Claude、DeepSeek、Qwen 等），跨 Web/macOS/Windows 平台运行。项目还衍生出 unspeech、xsai、MCP Launcher 等多个子项目。
🎯 适用领域 虚拟主播爱好者、AI 伴侣开发者、VTuber 技术研究者；需要自托管 AI 角色交互方案的个人；对 WebGPU/浏览器端 AI 推理感兴趣的前端开发者。

#4 andrewyng/aisuite
多家生成式 AI 供应商的统一接口
⭐ 15,662（+92 今日） Python 🍴 1,655 Forks
📖 详细介绍
aisuite 由吴恩达（Andrew Ng）发起，提供一套简单统一的接口来调用多家生成式 AI 供应商（OpenAI、Anthropic、Google 等）。核心价值是消除不同 LLM API 之间的差异，让开发者用一致的代码切换/对比模型，降低供应商锁定风险。定位轻量、易上手，适合做原型、多模型评测和教学演示。
🎯 适用领域 需要同时对接多家大模型的开发者、做模型对比评测的研究者、AI 教学场景。

#6 huggingface/speech-to-speech
Hugging Face 出品——用开源模型在本地构建语音对话 Agent
⭐ 7,178（+177 今日） Python 🍴 949 Forks
📖 详细介绍
huggingface/speech-to-speech 是 Hugging Face 官方推出的本地语音 Agent 框架，支持用完全开源的模型构建端到端语音对话系统。集成语音识别（STT）、LLM 对话推理、语音合成（TTS）三大模块，用户可以自由组合不同开源模型（如 Whisper、VAD、XTTS 等）构建低延迟的实时语音 Agent。支持本地服务器和云端提供商两种后端模式，无需依赖商业 API。需要 Python 3.10+。与商业语音方案相比，它强调完全本地化、数据隐私和模型可替换性。
🎯 适用领域 语音助手开发者、需要构建本地化语音交互系统的团队、对开源语音模型感兴趣的研究者、隐私敏感场景下的语音应用开发。

⭐ 3,347（+743 今日） TypeScript 🍴 389 Forks
📖 详细介绍
GeoLibre 是一款免费开源的轻量级 GIS（地理信息系统）平台，致力于在 Web 浏览器、桌面应用、移动端和 Jupyter Notebook 中统一运行，同时保持数据本地化与隐私。技术栈采用 Tauri v2 + React + TypeScript + MapLibre GL JS + DuckDB-WASM Spatial + deck.gl 构建，同一套代码可编译为原生桌面应用、Android 应用，并自适应响应式移动端界面。支持 3D Tiles 渲染、行星底图（地球、月球、火星、水星、金星、冥王星等）、SQL 工作空间、700+ 免费 GIS 工具、时间滑块动画、Zarr 数据存储等高级功能。与 QGIS 等桌面 GIS 相比，GeoLibre 强调零安装、跨平台和云端协作。
🎯 适用领域 地理数据分析师、GIS 研究人员、城市规划者、环境科学家；需要在浏览器中快速可视化和分析地理空间数据的团队；Jupyter Notebook 用户的地理数据工作流。
