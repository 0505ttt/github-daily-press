block/buzz 🐝
人类与 AI Agent 共享的协作工作区，基于自托管 Nostr 中继
9,239 ⭐
▲ +3,274 今日
Rust 🍴 708 Forks 📄 Apache 2.0
Block（原 Square）团队推出的自托管协作工作空间。核心理念是"Agent 是成员，不是机器人"——人与 AI Agent 共享同一频道和事件日志。底层基于 Nostr 协议，每条消息、代码补丁、工作流步骤都以签名事件形式存储在同一审计链中。Agent 拥有独立密钥对，可以打开代码库、发送补丁、运行 CI、审查代码、编辑画布，享有与人类团队成员相同的能力表面。桌面端基于 Tauri + React，支持 macOS / Linux / Windows。
适用领域
需要深度集成 AI Agent 到日常开发协作流程的技术团队、追求统一审计轨迹的合规导向组织、自托管优先的隐私敏感型企业

33,407 ⭐
▲ +506 今日
Python 🍴 5,675 Forks 📄 MIT
首个专门为金融市场 K 线（蜡烛图）序列数据预训练的开源 Foundation Model，在 45+ 全球交易所的数据上训练。采用两阶段框架：先通过专用 Tokenizer 将连续的 OHLCV 多维数据量化为分层离散 Token，再用大型自回归 Transformer 在这些 Token 上预训练。提供 mini（4.1M）/ small（24.7M）/ base（102.3M）三个开源模型版本，支持预测、分类、异常检测等多种量化任务，已被 AAAI 2026 接收。提供完整的 Qlib 微调和回测管线，支持多 GPU 训练和概率性预测。

离线隐私优先的英语语法检查器，Rust 驱动，极速轻量
12,877 ⭐
▲ +877 今日
Rust 🍴 479 Forks
由 Automattic（WordPress 母公司）开发的离线语法检查器，完全用 Rust 编写。创建动机是对 Grammarly（昂贵、隐私噩梦——所有文本发送到服务器）和 LanguageTool（需要 16GB n-gram 数据集、吃内存、速度慢）的不满。Harper 检查文档只需毫秒级，内存占用不到 LanguageTool 的 1/50，数据完全不离开本地设备。甚至可以通过 WebAssembly 在浏览器中直接运行，无需任何后端。提供 LSP 语言服务器（harper-ls）、Obsidian 插件、VS Code / Neovim / Helix / Emacs / Zed 等编辑器集成，以及 harper.js 浏览器库。
适用领域
注重隐私的写作者、离线环境下的文档工作者、编辑器开发者（集成 LSP）、不信任云语法检查的合规敏感团队

2,335 ⭐
▲ +884 今日
JavaScript 🍴 112 Forks 📄 MIT
