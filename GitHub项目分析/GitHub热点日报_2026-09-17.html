Go ⭐ 总计 31,643 今日 +3,215
详细介绍

open-code-review 采用「确定性流水线 + LLM Agent」的混合架构，能精确到行级别给出评审意见。它起源于阿里巴巴集团内部官方 AI 代码评审助手，过去两年服务了数万名开发者、识别出数百万个代码缺陷，经过超大规模实战检验后孵化开源。内置多语言规则集覆盖 NPE、线程安全、XSS、SQL 注入等高频问题，兼容 OpenAI 与 Anthropic 接口，配置一个模型端点即可用。区别于纯 LLM 评审工具，混合架构兼顾了确定性规则的准确率和 LLM 的灵活性，误报更少。

适用领域

中大型研发团队的代码质量把关与安全审计；希望引入 AI 代码评审但要求高准确率的工程团队。

cloudflare/security-audit-skill 🆕 首次上榜

Cloudflare 出品的编程 Agent 安全审计技能：六阶段流水线 + 对抗式验证
JavaScript ⭐ 总计 7,007 今日 +1,249
详细介绍

这是一个 coding-agent skill（npx skills add 一行装进 Claude Code 等编程 Agent），源自 Cloudflare 官方博客《Build your own vulnerability harness》中漏洞挖掘 harness 的单仓库起点。它编排多个隔离 Agent 走六阶段审计流水线：侦察（并行 Agent 映射架构、信任边界与输入面）→ 狩猎（多 Agent 按攻击类并行进攻：注入/访问控制/业务逻辑/密码学/链式攻击）→ 验证（独立 Agent 反过来试图推翻每条发现，对抗式杀死误报）→ 报告 → 结构化输出（符合 schema 的 findings.json 带校验脚本）→ 独立复核（全新 Agent 逐条核对事实声明）。多次运行是叠加式的：读取历史 findings.json 跳过已知问题、专攻未覆盖路径。对抗验证 + 机器可读输出 + 独立复核三重把关是它与普通 AI 审计工具的核心区别。

适用领域

用编程 Agent 的开发者做代码库安全自查；企业安全团队搭建自动化审计流水线；研究多 Agent 编排（对抗验证范式）的工程师。

知识归类：G-安全 › AI安全审计 › Agent化漏洞挖掘技能
#3

JustVugg/colibri 回榜第3次

纯 C 编写的极简 MoE 推理引擎：把 744B~2.8T 参数的前沿大模型搬进消费级硬件
C ⭐ 总计 34,968 今日 +1,532
详细介绍

Colibrì（蜂鸟）解决的问题是：前沿 MoE 大模型动辄几百上千亿参数，通常只有数据中心跑得动。它用纯 C 写成（每个模型一个 C 文件），零引擎依赖，核心思路是把 VRAM、内存和硬盘当成一整层「推理内存层级」——稠密部分常驻内存，上万个路由专家按需从 SSD 流式读取，靠 LRU 缓存和 OS 页缓存加速。目前已支持九个模型家族：GLM-5.2/5.3（744B）、Kimi K3（2.8T）、DeepSeek V4 Flash、Qwen3.8-Flash-Next 等，25GB 内存的消费机就能跑 744B 模型。技术亮点包括 MLA 权重吸收、原生 MTP 多 token 投机解码、int4/int8 整数点积内核，且所有优化都以 token 级精确对齐官方实现为前提。与 llama.cpp 等通用推理框架不同，它是专门针对 MoE 专家流式加载做的激进系统研究平台。

适用领域

想在个人电脑上本地跑前沿开源大模型的开发者；推理优化与系统方向的研究者；不想付 API 费用也不想被云厂商绑定的用户。

知识归类：A-AI/机器学习 › LLM推理框架 › 端侧MoE推理

abue-ammar/tinycast 🆕 首次上榜

3MB 的 macOS 全原生启动器：Raycast 的免费开源轻量替代，能直接跑 Raycast 扩展
Swift ⭐ 总计 5,542 今日 +1,136
详细介绍

Tinycast 是一个极小的 macOS 启动器：磁盘体积不到 3MB、内存占用 100MB 以内，用 SwiftUI 和 AppKit 原生构建，零第三方依赖、无 Electron、零遥测、无账号。功能覆盖一个热键调出应用模糊搜索、可搜索的剪贴板历史（文本+图片，直接贴回原应用）、内联计算器（数学/单位/实时汇率与加密货币换算）、Quicklinks、可复用 Markdown 片段模板、自定义 shell 命令绑定全局热键。最大亮点是能运行真正的 Raycast 扩展并以原生 SwiftUI 渲染，还支持直接读取 .rayconfig 导出文件一键迁移配置。与 Raycast/Alfred 相比走的是「免费开源 + 本地优先 + 无订阅」路线。

适用领域

嫌 Raycast 重、不想付费订阅的 Mac 用户；重视隐私（零遥测无账号）的用户；想从 Raycast 无痛迁移配置的效率工具玩家。

知识归类：I-系统/底层 › macOS效率工具 › 原生启动器

Lakr233/vphone-cli 🆕 首次上榜

在 Mac 上启动一台虚拟 iPhone：基于 Apple Virtualization.framework 与 PCC 研究 VM
Swift ⭐ 总计 13,313 今日 +444
详细介绍

vphone-cli 是一个命令行工具，利用 Apple 的 Virtualization.framework 配合 PCC（Private Cloud Compute）研究虚拟机基础设施，直接在 Apple Silicon Mac 上启动一台运行 iOS 26 的虚拟 iPhone。工作流是：创建空 VM → 下载并合并 IPSW 固件 → 给引导链打补丁 → 安装 CFW → 首次启动。提供五档固件变体（less/regular/dev/jb/exp），安全绕过程度递增：从只打 4 个补丁、保留全部 iOS 安全缓解的 patchless 版，到 141 个补丁、带完整越狱（Sileo/TrollStore 自动装）加反虚拟机检测的研究版。运行需要 Apple Silicon + macOS 15+ + 放宽 SIP/AMFI。仓库附 research/ 目录逐组件对比二进制补丁差异，工程文档扎实，Adafruit 博客曾专题报道。

适用领域

iOS 安全研究与越狱研究（不用真机就能跑可调试的 iOS）；逆向工程师做动态分析；探索 iOS 自动化测试的移动开发者。

知识归类：H-移动开发 › iOS虚拟化 › 虚拟iPhone启动器

Python ⭐ 总计 24,266 今日 +96
详细介绍

Anthropic 面向 Claude Cowork（兼容 Claude Code）的官方插件市场仓库。每个插件按岗位职能打包四件套——技能、连接器、斜杠命令、子 Agent：销售（研究潜客、备战电话、写外联、做竞争战卡）、客服（分诊工单、起草回复、沉淀知识库）、产品管理、法务（合同审查、NDA 分诊）、HR、数据分析等，接入 Slack/Notion/Jira/HubSpot 等工具。所有组件都是纯文件（markdown + JSON），无代码、无基础设施、无构建步骤。设计定位是「可定制的起点」：改 .mcp.json 换成自己的工具栈，往技能文件里塞公司术语和流程，Claude 就成了懂你们公司的岗位专家。Claude Code 一条命令即可安装指定插件，第三方（Noibu、Salesforce 等）已在贡献扩展插件。

适用领域

用 Claude Cowork/Claude Code 的团队按岗位装配标准化工作流；想让 Claude 接入办公工具链的知识工作者；研究 Agent 插件打包结构的开发者。

知识归类：B-开发者工具 › Claude插件 › 知识工作技能包
