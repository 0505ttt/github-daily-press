#1

openai/codex

OpenAI 官方终端编程 Agent，Rust 编写的轻量级 CLI

Rust ⭐ 总计 115,093 📈 今日 +2,729 🔁 累计 2 次上榜

详细介绍

OpenAI 官方开源的编码 Agent，用 Rust 编写、在终端本地运行，主打轻量与启动即用。除 CLI 外已形成完整矩阵：IDE 扩展（VS Code / Cursor / Windsurf）、桌面应用（codex app）以及云端版 Codex Web。登录方式支持 ChatGPT 账号（Plus / Pro / Business / Edu / Enterprise 套餐均包含）或 API key。安装路径覆盖 curl 一键脚本、npm（@openai/codex）与 Homebrew，并针对 macOS arm64/x86_64 和 Linux musl 提供独立二进制。Apache-2.0 协议，2025 年 4 月开源，是目前 OpenAI 在 AI 编程赛道对抗 Claude Code 的正面主力。

适用领域

习惯终端工作流、想用 OpenAI 模型做 AI 编程的开发者；已有 ChatGPT 订阅、希望零额外成本获得编码 Agent 的用户；需要在 IDE / 终端 / 云端之间保持同一 Agent 体验的团队。

详细介绍

作者「苍何」打造的中文社区项目，目标是把散落的 AI 图像生成案例变成 Agent 与自动化工作流可复用的 Prompt-as-Code 资产：将散文式提示词压缩成结构化协议，主体、光照、材质、版式、视觉细节拆为可组合的原子模块。目前已逆向工程 532 个案例（UI 界面 73、图表信息图 52、海报排版 86、电商产品 41、品牌 Logo 27、建筑空间 12、摄影写实 77 等），提炼 20+ 套工业级模板和避坑指南，并封装成可直接装进 Claude Code / Cursor 的 Agent Skill。配套在线画廊 gpt-image2.canghe.ai 支持按风格筛选、大图预览与一键复制提示词。区别于普通 awesome 合集的关键在于「结构化、可组合、面向批量生产」，适合真正要上生产流水线的图像生成场景。

适用领域

mattpocock/skills

给真正工程师的 AI Agent 技能集——直接来自 Matt Pocock 的 .agents 目录

Shell ⭐ 总计 233,766 📈 今日 +2,448 🔁 累计 4 次上榜

详细介绍

这是 TypeScript 教育领域知名人物 Matt Pocock（Total TypeScript 创始人）公开的日常 AI 编程技能集，核心理念是"做真正的工程，而不是 vibe coding"。项目针对 AI 编程助手的四大痛点提供解决方案：Agent 没做对（用 grill-me / grill-with-docs 深度对齐需求）、Agent 太啰嗦（构建共享语言 CONTEXT.md 减少沟通噪音）、代码不能用（TDD 红绿重构循环）、代码变泥球（improve-codebase-architecture 定期扫描架构）。技能分为用户调用（grill-me、to-spec、implement 等）和模型自动调用（tdd、diagnosing-bugs、code-review 等）两类，设计哲学强调小、可改、可组合。支持通过 npx skills@latest add 一键安装到 Claude Code、Codex 等。

适用领域

#4

basecamp/omarchy

DHH 出品的"开箱即用"美学 Linux 发行版——基于 Arch + Hyprland，装完即是成品

Shell ⭐ 总计 29,061 📈 今日 +814 🔁 累计 3 次上榜

详细介绍

Omarchy 是 Basecamp 创始人 DHH（David Heinemeier Hansson）打造的 Linux 发行版，定位"beautiful, modern & opinionated"——漂亮、现代、且观点鲜明。它基于 Arch Linux + Hyprland 平铺合成器，把字体、终端、状态栏、应用列表等桌面细节全部预先调校好，用户装完即得一套接近 macOS 质感的默认桌面，省去传统 Arch 安装后数天的配置折腾。作为"opinionated"发行版，它不提供大量开关，而是替用户做掉绝大多数决定：默认应用选型、按键绑定、主题风格均由 DHH 团队拍板，换来的是极高的一致性和低维护成本。已迭代到 v4.0.0，100+ 贡献者参与，2,600+ forks。与 NixOS 或 Ubuntu 这类通用发行版的区别在于：Omarchy 明确面向"想要 Mac 般顺滑 Linux 桌面体验"的开发者，牺牲自由度换取精致默认值。MIT 协议。

适用领域

适合想要一套省心、高颜值 Linux 桌面用于日常开发的程序员，尤其是从 macOS 迁移、不想陷入 Arch 手工配置的用户；也适合作为 Hyprland 窗口管理器最佳实践的参考实现。

知识归类

I-系统/底层 › Linux发行版 › 桌面环境整合

详细介绍

国产开源项目（作者 AprilNEA），用原生 Rust + GPUI 编写，通过 HID++ / UVC 协议直接驱动罗技鼠标、键盘和摄像头，彻底摆脱 Logitech Options+ 的臃肿、强制账号与遥测。功能全面超越官方：任意物理按键手势绑定、按键重映射（内置动作目录 + TOML 自定义快捷键）、按应用自动切换配置、DPI 预设与循环切换（0x2201）、SmartShift 滚轮模式（0x2111）、Litra 补光灯联动摄像头自动开关，以及 UVC 摄像头硬件级图像调节——缩放、曝光、白平衡等直写硬件，在 Meet / Zoom / OBS 等所有应用全局生效。跨 macOS / Linux / Windows 三平台且 Linux 为一等公民，全部配置浓缩为一个可同步的 TOML 纯文本文件，GUI 之外还提供真正的 CLI。2026 年 5 月创建即冲上 Trendshift，已登陆 Product Hunt。

适用领域

受够 Options+ 臃肿与隐私问题的罗技 MX Master 等外设用户；Linux 桌面用户（官方几乎放弃的平台）；喜欢纯文本配置、可版本管理外设设置的极客。

知识归类

block/buzz

人机协作的群体智能工作空间

Rust ⭐ 总计 30,065 📈 今日 +349 🔁 累计 6 次上榜

详细介绍

Buzz 由 Block 公司（原 Square）出品，定位为"蜂巢式（hive mind）协作平台"。底层本质是一个自托管的 Nostr relay：每条消息、反应、工作流步骤、代码评审、git 事件都是一条签名事件，人和 Agent 共享同一套身份模型与审计轨迹。外观像团队工作区，内核是事件日志。支持自建 relay，数据自主可控。区别于 Slack/Discord 的核心在于——Agent 是一等公民，与人类平权协作。

适用领域

希望让 AI Agent 深度融入团队协作流程的技术团队，重视数据主权、自托管需求，以及对人机协同工作流感兴趣的组织。

#7

apache/maka

Apache 孵化中的本地优先 Agent 工作区，一切执行皆可追溯、可恢复

TypeScript ⭐ 总计 2,322 📈 今日 +49 🔁 累计 2 次上榜

详细介绍

Apache 孵化器项目（2026 年 5 月进入孵化），定位「为真实工作构建的 local-first Agent 工作区」。核心设计是把模型消息、工具调用、工具结果、权限决策、终止事件全部写入 append-only log——UI 和下一次模型调用只是这份记录的视图，而非唯一副本，因此「缩短上下文 ≠ 删除历史」，崩溃后可恢复、可中途续跑被打断的回合。桌面（Electron + React，macOS Apple Silicon 早期公测）、终端（maka / maka run）与评测（maka eval，声明式多臂实验、逐单元格不可变记录）三个入口统一走同一个 Runtime Host。内置 Read / Write / Edit / Bash / Glob / Grep 工具，出沙箱操作必须人工审批；模型自带——云 API、本地模型或网关皆可。与商业 Agent 工作区的区别：数据默认留在本机 + Apache 基金会治理的中立生态。尚未发布 Apache 正式版，目前需源码构建。

适用领域

重视数据主权与执行审计的 Agent 重度用户；需要可复现评测实验的 AI 工程师；偏好基金会治理、担心商业工作区锁定的团队。

知识归类

B-开发者工具 › Agent工作空间 › 本地优先工作区

Alishahryar1/free-claude-code

聚合 49 个免费模型提供商，让 9 款编码 Agent 每月白嫖 13 亿+ token

Python ⭐ 总计 47,913 📈 今日 +1,040 🔁 累计 2 次上榜

详细介绍

FCC 是一个本地代理服务（Python 3.14，MIT 协议，与 Anthropic 无关联），把免费、付费、订阅与本地模型聚合进一个可搜索的统一目录，供 Claude Code、Codex、Pi、OpenCode、Cline、Hermes、DeepSeek Harness、Grok Build、Muse Code 九款编码 Agent 使用，宣称每月合计 1.3B+ 免费 token。最大卖点是「ToS 友好」：遵循各提供商服务条款，不再被允许的集成就下架。工程细节扎实：提供商故障时重试耗尽自动切换下一个模型、不用重启回合；可选 RTK 过滤器最高砍掉 90% 终端输出 token；支持本地 Whisper / NVIDIA NIM 语音输入；使用入口覆盖终端、桌面、VS Code、JetBrains，甚至 Discord 与 Telegram 手机端。与简单 API 中转的区别：面向编码 Agent 生态做了工具调用、交织思考、图像输入等能力保真，并保留 Opus / Sonnet / Haiku 独立路由。

适用领域

想零成本试用顶级编码 Agent 的学生与个人开发者；需要在多个模型提供商间自动容错切换的重度用户；想用手机/语音远程驱动编码 Agent 的折腾党。

知识归类

适用领域

想要「越用越懂你」的个人 AI 助手的重度用户；重视本地数据隐私、希望记忆可导出可审计的人；想统一编排多个 Agent 与自动化工作流的效率极客。
