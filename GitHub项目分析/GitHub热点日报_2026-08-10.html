一个自改进的 RLM（递归语言模型）Agent，专为编码工作流和长时间运行的自主任务设计
📖 详细介绍

Prime Agent 是 Prime Intellect 团队的开源编码与研究 Agent，围绕两大核心抽象构建：Recursive Language Model（RLM）——将上下文视为变量、将工具和递归子 Agent 视为函数调用，运行在持久化的 Python REPL 中；以及 Continual Harness——将持久控制环境与可保存的 harness 状态结合，使有用的工作上下文和可复用的操作模式能跨会话存活。它专为长时间运行的研究评测任务而生，支持后台自主运行、技能系统和多 Provider 接入，提供 TUI 和 JSON/RPC 模式。MIT 协议，截至当前已有 41 个 release、4,480+ commits。

🎯 适用领域

需要长时间自主编码任务的研究人员与工程师、AI Agent 评测研究者、需要持久化上下文与可复用工作流的深度 Agent 用户、偏好开源可自托管 Agent 方案的技术团队。

知识归类：A-AI/机器学习 › Agent框架 › 自改进RLM智能体

🎯 适用领域

维护大型 Monorepo 的工程团队、需要 AI 深度理解代码结构和依赖关系的开发者、MCP 生态用户、想用自然语言重构和查询复杂代码库的技术团队。

"这玩意儿为什么在运行？"——追踪任何进程、端口、容器或文件的来源，CLI + TUI 双模式
📖 详细介绍

witr（Why Is This Running）是一个用 Go 编写的系统进程溯源工具，解决一个经典痛点：看到一个进程/端口在跑却不知道是谁启动的。它能将任意进程、端口、容器或文件反向追踪到启动它的源头——父进程、容器、服务、定时任务等。提供 CLI 和交互式 TUI 两种界面，支持 Linux 的 D-Bus 和 /proc 高效读取（避免子进程 fork 开销），跨平台支持（含 Windows PowerShell 安装脚本）。20K+ stars、588 commits、21 个 Tag、有 Nix flake 支持，还有专属 llms.txt 供 LLM 阅读项目摘要。

🎯 适用领域

运维工程师和 SRE、排查异常进程的系统管理员、容器环境调试开发者、偏好终端工具而非图形界面的系统极客、需要快速定位"谁占用了端口"的开发者。

知识归类：I-系统/底层 › 进程管理 › 进程溯源工具
