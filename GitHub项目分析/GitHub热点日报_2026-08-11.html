1 semantica-agi / semantica Python今日 +967⭐
主语言：Python ⭐ 总计：4,032 今日新增 +967
图原生的 AI 上下文基础设施——为 AI 系统提供结构化上下文、因果推理和完整决策溯源
📖 详细介绍

Semantica 是一个开源的图原生（Graph-Native）基础设施层，解决 AI Agent 缺乏结构化上下文和决策可审计性的问题。它通过知识图谱摄入企业数据，自动提取实体、关系和语义信息，构建可查询的上下文图谱（Context Graph）。核心能力包括：为 LLM/Agent 提供可追溯的推理路径（provenance）、支持因果推理和语义搜索、内置本体（ontology）引擎让数据具有语义层。与传统向量数据库 RAG 的区别在于：Semantica 用图谱关系而非向量相似度做检索，决策过程可解释、可审计。MIT 协议，已发布 v0.6.0，支持 pip install semantica。

🎯 适用领域

需要可解释 AI 决策的企业团队、构建 Agent 的开发者（需要给 Agent 提供结构化知识上下文）、知识图谱/语义搜索方向的工程师、需要决策溯源与合规审计的金融/法律/医疗场景。

知识归类：A-AI/机器学习 › 知识图谱 › Agent上下文基础设施

MediaCrawler 是一个功能强大的多平台自媒体数据采集工具，支持小红书、抖音、快手、B站、微博、百度贴吧、知乎七大主流平台的公开信息抓取，涵盖笔记/视频/帖子内容及其评论（含二级评论）。核心技术基于 Playwright 浏览器自动化框架登录并保存登录态，利用浏览器上下文通过 JS 表达式获取签名参数，无需逆向复杂加密算法即可绕过平台反爬。支持关键词搜索、指定帖子ID爬取、指定创作者主页、IP代理池、登录态缓存、生成评论词云图等功能，提供 WebUI 可视化界面和 PostgreSQL 持久化存储。最大优势是大幅降低了技术门槛——无需逆向即可采集数据。

🎯 适用领域

社交媒体数据分析师、舆情监控团队、市场研究人员、NLP/推荐系统数据准备者；需要多平台公开内容批量采集的场景（仅限学习研究用途）。

从零构建的真正独立浏览器——不 fork 任何现有引擎，挑战 Chrome/Firefox 双寡头
📖 详细介绍

Ladybird 是自 Firefox 以来首个真正从零开始构建的独立浏览器引擎项目。由前 Apple WebKit 开发者 Andreas Kling 创立，不是任何现有浏览器的 fork——自己实现 HTML/CSS/JS 引擎（LibWeb 和 LibJS），从 SerenityOS 项目独立发展而来。2024 年成立非营利组织 Ladybird Browser Initiative 接管，计划 2026 年发布 Alpha 版。最近宣布将采用 Swift 作为未来语言。6.5 万 stars 的社区体量说明市场对打破 Chromium/Gecko/WebKit 三引擎垄断格局的强烈期待。项目在技术上代表了一种"理想主义"：在大家都用 Chromium 的时代，还有人愿意从第一性原理重新造浏览器。

🎯 适用领域

浏览器引擎/Web 标准研究者、关注 Web 平台多元化的开发者、C++ 系统编程爱好者、开源理想主义支持者、想要理解浏览器内部工作原理的学习者。

知识归类：C-前端/Web › 浏览器引擎 › 从零构建独立浏览器

📖 详细介绍

Firecrawl 是 Y Combinator（S22）孵化的 Web 数据 API 平台，定位为"AI Agent 的数据管道"。核心能力：一个 API 调用就能把任意 URL 转换为干净的、LLM 可直接使用的 Markdown 或结构化数据；支持大规模爬取、搜索和与 Web 交互。技术亮点包括智能 JS 渲染（处理 SPA/动态内容）、反爬绕过、自动分块和结构化提取。已完成 $1,450 万 A 轮融资（Nexus Venture Partners 领投，总融资 $1,620 万），是 AI 爬虫赛道商业化最成功的项目之一。16.5 万 stars 的体量使其成为 AI 数据基础设施的事实标准之一。与 Playwright/Puppeteer 等通用爬虫的区别：Firecrawl 专注为 LLM 优化的输出——Markdown 格式、干净文本、结构化 JSON。

🎯 适用领域
