#1
openai/codex
OpenAI 官方终端编程 Agent，Rust 编写的轻量级 CLI
今日 ⭐ +2,729 总计 ⭐ 114,793 Rust

详细介绍

OpenAI 官方开源的编码 Agent，用 Rust 编写、在终端本地运行，主打轻量与启动即用。除 CLI 外已形成完整矩阵：IDE 扩展（VS Code / Cursor / Windsurf）、桌面应用（codex app）以及云端版 Codex Web。登录方式支持 ChatGPT 账号（Plus / Pro / Business / Edu / Enterprise 套餐均包含）或 API key。安装路径覆盖 curl 一键脚本、npm（@openai/codex）与 Homebrew，并针对 macOS arm64/x86_64 和 Linux musl 提供独立二进制。Apache-2.0 协议，2025 年 4 月开源，是目前 OpenAI 在 AI 编程赛道对抗 Claude Code 的正面主力。

适用领域

习惯终端工作流、想用 OpenAI 模型做 AI 编程的开发者；已有 ChatGPT 订阅、希望零额外成本获得编码 Agent 的用户；需要在 IDE / 终端 / 云端之间保持同一 Agent 体验的团队。

知识归类：B-开发者工具 › AI编程工具 › 终端编程Agent
#2
freestylefly/awesome-gpt-image-2
GPT-Image2 工业级提示词引擎与模板库，「Prompt as Code」理念
今日 ⭐ +628 总计 ⭐ 12,462 JavaScript

详细介绍

作者「苍何」打造的中文社区项目，目标是把散落的 AI 图像生成案例变成 Agent 与自动化工作流可复用的 Prompt-as-Code 资产：将散文式提示词压缩成结构化协议，主体、光照、材质、版式、视觉细节拆为可组合的原子模块。目前已逆向工程 532 个案例（UI 界面 73、图表信息图 52、海报排版 86、电商产品 41、品牌 Logo 27、建筑空间 12、摄影写实 77 等），提炼 20+ 套工业级模板和避坑指南，并封装成可直接装进 Claude Code / Cursor 的 Agent Skill。配套在线画廊 gpt-image2.canghe.ai 支持按风格筛选、大图预览与一键复制提示词。区别于普通 awesome 合集的关键在于「结构化、可组合、面向批量生产」，适合真正要上生产流水线的图像生成场景。

适用领域

用 GPT-Image2 做批量营销图、电商素材、海报排版的设计师与运营；想把图像生成接入 Agent 自动化工作流的开发者；研究提示词工程与模板化生产的 AI 从业者。

知识归类：A-AI/机器学习 › 提示词工程 › 图像生成

详细介绍

TypeScript 教育领域知名人物 Matt Pocock（Total TypeScript 创始人）公开的日常 AI 编程技能集，直击 AI 编程助手四大失败模式：Agent 没做对你想要的（用 /grill-me、/grill-with-docs 深度盘问对齐需求）、Agent 太啰嗦（构建共享语言 CONTEXT.md 与 ADR，让 Agent 用「一个词代替二十个词」）、代码不能用（/tdd 红绿重构循环 + /diagnosing-bugs 纪律化排障）、代码变泥球（/improve-codebase-architecture 定期扫描架构深化机会）。技能分为用户调用与模型自动调用两类，强调小、可改、可组合，适用于任何模型。一条命令即可装进 Claude Code（官方插件市场）或 Codex 等其它 Agent。与 GSD、BMAD、Spec-Kit 等接管式流程框架的区别：不夺走控制权，只提供可自由魔改的工程纪律。

适用领域

知识归类：B-开发者工具 › AI编程工具 › Agent技能集
#4
basecamp/omarchy
DHH 出品的「开箱即用」美学 Linux 发行版（第二次上榜）
今日 ⭐ +803 总计 ⭐ 28,688 Shell

详细介绍

Basecamp 创始人 DHH 打造的 Linux 发行版，定位「beautiful, modern & opinionated」。基于 Arch Linux + Hyprland 平铺合成器，把字体、终端、状态栏、应用选型、快捷键、主题等桌面细节全部预先调校好，装完即得一套接近 macOS 质感的默认桌面，省去传统 Arch 装机后数天的配置折腾。作为 opinionated 发行版，它不提供大量开关，而是替用户做掉绝大多数决定，换来极高一致性与低维护成本。自带 52 章的官方手册（manual/ 目录），覆盖从入门、双系统安装到 dotfiles、系统快照的全部场景，还支持 Windows 虚拟机与无人值守安装。与 NixOS / Ubuntu 等通用发行版的区别：明确面向「想要 Mac 般顺滑 Linux 桌面」的开发者，牺牲自由度换取精致默认值。MIT 协议。

适用领域

想要一套省心、高颜值 Linux 桌面用于日常开发的程序员，尤其是从 macOS 迁移、不想陷入 Arch 手工配置的用户；也适合作为 Hyprland 窗口管理器最佳实践的参考实现。

知识归类：I-系统/底层 › Linux发行版 › 桌面环境整合

今日 ⭐ +1,008 总计 ⭐ 14,469 Rust

详细介绍

国产开源项目（作者 AprilNEA），用原生 Rust + GPUI 编写，通过 HID++ / UVC 协议直接驱动罗技鼠标、键盘和摄像头，彻底摆脱 Logitech Options+ 的臃肿、强制账号与遥测。功能全面超越官方：任意物理按键手势绑定、按键重映射（内置动作目录 + TOML 自定义快捷键）、按应用自动切换配置、DPI 预设与循环切换（0x2201）、SmartShift 滚轮模式（0x2111）、Litra 补光灯联动摄像头自动开关，以及 UVC 摄像头硬件级图像调节——缩放、曝光、白平衡等直写硬件，在 Meet / Zoom / OBS 等所有应用全局生效。跨 macOS / Linux / Windows 三平台且 Linux 为一等公民，全部配置浓缩为一个可同步的 TOML 纯文本文件，GUI 之外还提供真正的 CLI。2026 年 5 月创建即冲上 Trendshift，已登陆 Product Hunt。

适用领域

受够 Options+ 臃肿与隐私问题的罗技 MX Master 等外设用户；Linux 桌面用户（官方几乎放弃的平台）；喜欢纯文本配置、可版本管理外设设置的极客。

知识归类：I-系统/底层 › 外设工具 › 罗技驱动替代
#6
block/buzz
Block 出品的「蜂巢式」人机协作工作空间，内核是 Nostr relay（第二次上榜）
今日 ⭐ +564 总计 ⭐ 29,913 Rust

详细介绍

Block（原 Square，Jack Dorsey 创办）出品的自托管协作平台，外观是团队工作区，内核是一个 Nostr relay：每条消息、表情反应、工作流步骤、代码评审、git 事件都是一条签名事件，人与 Agent 共享同一套身份模型与审计轨迹——Agent 是「成员」而非「机器人」，加进频道的方式和加一个人相同。Agent 在里面能开仓库、发补丁、跑工作流、做首轮代码评审、进入语音会议、编排其它 Agent，权限按身份而非标志位划界。特色玩法包括「分支即房间」（功能分支自动生成频道，补丁以 NIP-34 事件落地、CI 结果与合并决定同处一室）和「会写自己的发布说明」（工作流触发后 Agent 汇总已合并 PR 起草 release notes，人类点个 👍 即发布）。已落地：relay、频道、DM、画布、搜索、Tauri 桌面端、agent-first 的 buzz-cli 与 YAML 工作流；移动端与审批门在推进中。Apache-2.0 协议。

适用领域

希望让 AI Agent 深度融入团队协作流程的技术团队；重视数据主权、需要自托管与完整审计轨迹的组织；研究人机协同工作流与 Nostr 协议落地的开发者。

知识归类：A-AI/机器学习 › Agent协作平台 › 人机工作空间 / Nostr
#7
apache/maka
Apache 孵化中的本地优先 Agent 工作区，一切执行皆可追溯、可恢复
今日 ⭐ +49 总计 ⭐ 2,206 TypeScript

详细介绍

Apache 孵化器项目（2026 年 5 月进入孵化），定位「为真实工作构建的 local-first Agent 工作区」。核心设计是把模型消息、工具调用、工具结果、权限决策、终止事件全部写入 append-only log——UI 和下一次模型调用只是这份记录的视图，而非唯一副本，因此「缩短上下文 ≠ 删除历史」，崩溃后可恢复、可中途续跑被打断的回合。桌面（Electron + React，macOS Apple Silicon 早期公测）、终端（maka / maka run）与评测（maka eval，声明式多臂实验、逐单元格不可变记录）三个入口统一走同一个 Runtime Host。内置 Read / Write / Edit / Bash / Glob / Grep 工具，出沙箱操作必须人工审批；模型自带——云 API、本地模型或网关皆可。与商业 Agent 工作区的区别：数据默认留在本机 + Apache 基金会治理的中立生态。尚未发布 Apache 正式版，目前需源码构建。

适用领域

重视数据主权与执行审计的 Agent 重度用户；需要可复现评测实验的 AI 工程师；偏好基金会治理、担心商业工作区锁定的团队。

知识归类：B-开发者工具 › Agent工作空间 › 本地优先工作区
