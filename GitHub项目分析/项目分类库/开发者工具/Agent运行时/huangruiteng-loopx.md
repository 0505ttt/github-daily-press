## 详细介绍
LoopX 不替换你的 Agent 运行时，而是为它外挂一层持久控制状态：目标（objective）、门禁（gates）、待办（todos）、范围（scope）、证据（evidence）、配额（quota）。它把 Agent 协作可视化为一张"Agent 原生看板"——卡片承载身份、权限、证据和续接，移动是经过校验的操作算子（claim / gate / monitor / writeback）。Agent 之间是平等的 peer 关系，靠 claim、lease、任务边界和类型化续接来决定谁下一步行动，无需固定的"领导者"。亮点在于可处理跨 200+ 小时的长程任务轨迹（如开源 Issue 修复、Auto ML 实验），让证据、谱系、晋升/停止门禁始终可查。危险权限、发布、最终归属始终留给人类。

## 适用领域
运行多日工程/研究/实验类长任务的 Agent 团队；Issue 与 PR 循环需保留范围与证据；需要把 Agent 工作产出"对非工程操作者可读"的研究/运营/创作工作流。
