## 详细介绍
一个 MCP 服务器，通过 Chrome DevTools Protocol（CDP）将 Claude Code 连接到本地运行的 TradingView 桌面应用，实现 AI 辅助图表分析。功能涵盖 Pine Script 开发（编写/注入/编译/调试）、图表导航（切换标的/时间框架/缩放）、视觉分析（读取指标值/价格水平）、图表绘制（趋势线/水平线/矩形/文本）、告警管理、历史回放练习和截图。所有数据处理在本地完成，不传输或存储市场数据。提供 81 个 MCP 工具，同时附带 CLI 命令行工具。项目明确声明这不是交易机器人，而是让交易界面「对 LLM 可读」的接口层。
