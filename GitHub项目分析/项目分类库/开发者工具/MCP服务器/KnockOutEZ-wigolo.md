## 详细介绍
一个通过 MCP 协议为 AI 编程助手（如 Claude Code）提供网络访问能力的 TypeScript 项目。无需 API 密钥、无需云端服务、每次查询零成本，所有功能在本地运行。支持网页搜索、内容抓取、网站爬取和深度研究四种模式，让 AI 编程 Agent 能自主获取网络信息辅助编码。目前处于公测阶段，日增 605 star 显示出强劲势头。

## 适用领域
Claude Code / Cursor 等 MCP 客户端用户、需要 AI Agent 具备网络搜索能力的开发者
