这是 Google 官方维护的 Agent Skills 仓库，为 Google 全系产品和技术（GCP、Android、TensorFlow、Gemini 生态等）提供 AI Agent 可用的技能包。每个 Skill 是一组结构化的指令和能力定义，让 AI 编码 Agent 在处理 Google 技术栈相关任务时更准确、更符合最佳实践。由 Google 内部多个团队（cloud-ix-copybara、holtskinner、martinvarelaj 等）协同维护。17K+ stars，体现了大厂对 Agent 技能标准化方向的重视——与 addyosmani/agent-skills（个人工程师向）形成互补。
