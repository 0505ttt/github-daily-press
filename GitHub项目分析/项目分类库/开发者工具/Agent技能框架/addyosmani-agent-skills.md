## 详细介绍
Google 工程师 Addy Osmani 出品的 24 个生产级 Agent 技能集合，把资深工程师的工作流、质量门禁与最佳实践打包成 Agent 可一致遵循的能力。8 个斜杠命令对应开发生命周期：`/spec`（先规格后代码）、`/plan`（原子化任务）、`/build`（一次一个切片）、`/test`（测试即证据）、`/review`、`/webperf`、`/code-simplify`、`/ship`。`/build auto` 可批准一次计划后自动实现每个任务（仍逐个测试驱动提交，遇失败/风险暂停）。技能还会根据当前工作自动激活（设计 API 触发接口设计技能，做 UI 触发前端工程技能）。通过开放 skills CLI 一键装入 70+ Agent 平台。

## 适用领域
想让 AI 编码助手遵循专业开发流程的开发者和团队、Claude Code/Cursor/Codex/Copilot 用户、追求 AI 自动化开发效率的个人与组织。
