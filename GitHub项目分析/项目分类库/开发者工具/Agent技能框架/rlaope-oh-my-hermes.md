## 详细介绍
oh-my-hermes（OMH）是给 Hermes Agent 加装的"专业运营层"：一次安装，不替换 Hermes，在其原生技能之上框定问题、挑选工作流和证据门槛，再把原生技能作为能力放进受治理的执行路径里跑。核心卖点是把一个普通的自然语言请求变成"清晰的能力 + 有用的下一步 + 诚实的过程记录"——规划、研究、创作、编码交接、运维、项目记忆全覆盖，且带显式的证据边界（evidence boundaries），不夸大 Agent 实际做了什么。技术形态上提供 116 个可安装技能、9 条 ULW 工作流、7 个能力家族，支持 Homebrew/Bun/npm/curl 安装，能路由 Claude Code、Codex、pi 等多个编码执行器（谁装了用谁，不绑定默认厂商），模型池直接用你已付费的 Claude/GPT/Gemini/DeepSeek/Qwen/Kimi 等。与直接换用重型 Agent 框架不同，它强调"永不修改 Hermes 本体、执行器中立、本地契约"。当前处于早期（约 2K star），star 绝对量小但已进 Trending。

## 适用领域
Hermes Agent 用户想强化日常开发工作流（编码交接给 Claude Code/Codex、带证据门槛的深度研究）；需要长期项目记忆和"诚实汇报"的独立开发者；管理多编码 Agent/多模型订阅、想统一路由调度的重度用户。
