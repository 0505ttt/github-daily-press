## 详细介绍
这是 Obsidian 官方 CEO Steph Ango（kepano）发布的 Agent Skills 集合，遵循 Agent Skills 规范（agentskills.io），可被任何兼容 Skills 的 Agent 使用——包括 Claude Code、Codex、Open Code 等。包含 5 个核心技能：obsidian-markdown（创建和编辑 Obsidian 风味 Markdown，含 wikilinks、embeds、callouts、properties 等）、obsidian-bases（创建和编辑 Obsidian Bases 数据库视图，含筛选、公式、摘要）、json-canvas（创建和编辑 JSON Canvas 画布文件，含节点、边、分组）、obsidian-cli（通过 Obsidian CLI 操作 vault，含插件和主题开发）、defuddle（使用 Defuddle 从网页提取干净 Markdown，节省 token）。支持通过 Plugin Marketplace、npx skills 或手动安装。

## 适用领域
Obsidian 用户、使用 Claude Code / Codex 编程 Agent 同时管理 Obsidian vault 的开发者、笔记驱动的知识管理爱好者、PKM（个人知识管理）从业者。
