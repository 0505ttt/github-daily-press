## 详细介绍
Superpowers 是一套完整的面向编码 Agent 的软件开发方法论，构建在一组可组合技能和初始指令之上，让 AI 编码助手自动遵循专业开发流程。核心流程：Agent 不会急于写代码，而是先与用户对齐需求，拆解出可消化的小块规格说明；设计确认后，自动生成一份清晰到「连初级工程师都能照做」的实现计划；用户说"go"后，启动子代理驱动开发（subagent-driven-development），让多个 Agent 分别处理各个工程任务并互相审查。强调真正的红/绿 TDD（测试先行）、YAGNI（不做不需要的功能）和 DRY 原则。Agent 可自主工作数小时而不偏离计划。支持 Claude Code、Codex、Cursor、Gemini CLI、GitHub Copilot CLI、Kimi Code、OpenCode 等 11+ 平台。与 ECC 等技能仓库相比，Superpowers 更侧重方法论和流程自动化，而非单纯技能堆砌。

## 适用领域
重度使用 AI 编程工具的开发者和团队；希望让 AI Agent 遵循专业 TDD 流程的工程团队；追求 AI 自主开发效率最大化的个人开发者；需要跨多个 AI 编程平台共享开发方法论的组织。
