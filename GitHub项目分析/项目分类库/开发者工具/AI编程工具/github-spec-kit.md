## 详细介绍
Spec Kit 由 GitHub 官方开发，是一个推行 Spec-Driven Development（规格驱动开发）的开源工具包。核心理念是翻转传统开发流程：先写规格（what & why），再由 AI Agent 生成实现。提供 Specify CLI 工具和 7 个斜杠命令：/speckit.constitution（项目原则）→ /speckit.specify（需求规格）→ /speckit.plan（技术方案）→ /speckit.tasks（任务分解）→ /speckit.implement（执行实现）。支持 30+ AI 编程助手集成（Claude Code、Copilot、Codex、Cursor 等），并提供 Extensions（扩展新能力）、Presets（定制工作流）、Bundles（角色化配置包）三层定制体系。

## 适用领域
使用 AI 编程助手的开发团队、技术负责人；希望规范 AI 辅助开发流程的组织；需要从需求到实现全流程结构化的产品工程团队。
