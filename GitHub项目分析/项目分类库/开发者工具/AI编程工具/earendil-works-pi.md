## 详细介绍
由 libGDX 游戏框架作者 Mario Zechner（badlogic）2025 年 8 月创建，2026 年 4 月并入 Flask 作者 Armin Ronacher 创办的 Earendil 公司（公共利益企业）。设计哲学是「极简内核 + 自扩展」：内置工具只有 read/write/edit/bash 四个，其余能力全部通过 TypeScript 扩展、Agent Skills 和 prompt 模板注入；会话用 JSONL 分支树存储，/tree /fork /clone 可以原地分叉历史；pi-ai 统一 35+ 家模型提供商（含任意 OpenAI 兼容端点、Ollama、vLLM、LM Studio）。它刻意不做子代理、计划模式、权限弹窗和 MCP——作者认为这些「隐藏注入」损害可控性；官方文档给出三种容器化沙箱方案（Gondolin 微虚机、Docker、OpenShell）。生态位已相当稳固：OpenClaw、MiniMax Code 等知名产品都以它为底座。

## 适用领域
想要可控、可审计、极简编码 Agent 的资深开发者；想基于 pi-ai / pi-agent-core 自建 Agent 产品的团队；研究 Agent 架构设计的工程师。
