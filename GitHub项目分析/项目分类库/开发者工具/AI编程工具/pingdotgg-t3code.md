## 详细介绍
T3 Code 是一个极简的 Web GUI，用于管理和驱动各类 AI 编码 Agent（目前支持 Codex、Claude、Cursor、OpenCode，更多即将支持）。由知名开发者/YouTuber Theo（t3dotgg）开发，是 T3 生态的一部分（与 create-t3-app、t3.chat 同系列）。核心理念是"一个界面管理所有 AI 编码工具"，让你不必在多个终端窗口和 Agent 之间切换。项目完全开源，基于 TypeScript 构建，专为喜欢在浏览器中操作 AI Agent 的开发者设计。与同类工具的区别在于其极简设计和对多种 Agent 的统一抽象。

## 适用领域
同时使用多种 AI 编码 Agent 的开发者、偏好 Web 界面而非终端的 AI 辅助编程用户、T3 Stack 生态用户
