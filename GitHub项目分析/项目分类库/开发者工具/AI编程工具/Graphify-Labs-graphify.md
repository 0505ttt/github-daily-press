## 详细介绍
Graphify 是一个 AI 编程助手技能（Skill），支持 Claude Code、Codex、OpenCode、Cursor、Gemini CLI 等多种工具。它将任意文件夹中的代码、SQL Schema、R 脚本、Shell 脚本、文档、论文、图片或视频转化为可查询的知识图谱，将应用代码 + 数据库 Schema + 基础设施统一到一个图中。核心能力包括：自动代码解析与实体提取、社区检测算法、置信度评分、以及基于图结构的智能查询。项目还推出了商业产品 Penpax——一个始终在线的个人知识层，持续索引会议、浏览器历史、邮件和文件。支持 Docker MCP Toolkit + SQLite 集成。

## 适用领域
使用 AI 编程助手的开发者、大型代码库维护者；需要快速理解陌生代码库的工程师；希望将分散的文档和代码统一为知识图谱的团队。
