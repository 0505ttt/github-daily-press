## 详细介绍
由 Moonshot AI（月之暗面）开发的终端 AI 编程 Agent（Kimi Code CLI）。能读取和编辑代码、执行 shell 命令、搜索文件、抓取网页，完整覆盖软件开发工作流。与 VS Code 集成，支持 shell 命令模式，并配有 Kimi Agent SDK 可将 Agent 运行时嵌入应用。正在进化为 Kimi Code——下一代终端 AI Agent，配合 Kimi K2.5 模型效果最佳。

## 适用领域
