## 详细介绍
Munder Difflin 是一个免费开源的本地多 Agent harness，名字戏仿《办公室》里的"Munt"。它把 Claude Code、Antigravity（Gemini）、OpenAI Codex、xAI Grok、Kimi Code、Qwen 等你已经在付费订阅的终端编程 CLI 包装成一个个"克隆员工"，让它们在你不在线时继续干活，并在你自己的机器上协调成一间办公室。所有 Agent 之间可以互发消息、路由任务、共享记忆，由一个代表你的"主管克隆"（Michael）统一调度，再用 Pixi.js 把每个 Agent 渲染成在共享办公楼层里上班的虚拟形象，进度一目了然。技术栈是 Electron + React + TypeScript + xterm.js + node-pty，纯本地运行，自带 API Key 即用，也支持本地 LLM。与 LangChain 类编排框架的区别在于：它不要求你写代码定义 Agent，而是直接复用现成订阅的编程 CLI 按小时额度编排，上手门槛接近零。

## 适用领域
适合已经订阅一个或多个 AI 编程 CLI 的开发者，想让多个 Agent 并行干活、夜间无人值守续跑长任务、或观察多 Agent 协作过程的团队；对研究 Agent 间通信与调度的爱好者也有参考价值。
