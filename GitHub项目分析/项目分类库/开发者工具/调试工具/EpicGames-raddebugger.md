## 详细介绍
RAD Debugger 是一个原生的、用户态的、支持多进程的图形化调试器，由传奇工具团队 RAD Game Tools（2021 年被 Epic Games 收购）开发并开源。它目前支持本机 Windows x64 调试和 PDB 符号，未来计划扩展 Linux 原生调试和 DWARF 调试信息。项目不止于调试器本身，还配套推进两项相关技术：自研的 RDI 调试信息格式（按需把 PDB 转换为 RDI，解析更快）和 RAD Linker 链接器，目标是重塑整条调试工具链。架构上分为 dbgi/raddbg/coord_layer 等多层，ctrl 层实现异步进程控制、单步和断点，与被调试进程锁步运行。目前处于 ALPHA 阶段，官方鼓励用户积极提交 issue。

## 适用领域
Windows 平台的原生 C/C++ 开发者、游戏引擎与高性能程序开发者；需要多进程同时调试、对调试器性能（加载大 PDB、大可执行文件）有苛刻要求的场景；研究调试器内部实现与调试信息格式（RDI）的系统程序员。
