## 详细介绍
open-code-review 是阿里巴巴开源的代码评审工具，采用"确定性流水线 + LLM Agent"的混合架构，能在精确到行级别给出评审意见。内置经过微调的规则集（NPE、线程安全、XSS、SQL 注入等），兼容 OpenAI 与 Anthropic 接口。在阿里巴巴内部大规模实战检验过（Battle-tested at Alibaba's scale）。区别于纯 LLM 评审工具，混合架构兼顾了确定性的准确率和 LLM 的灵活性。

## 适用领域
中大型研发团队的代码质量把关、安全审计场景，希望引入 AI 代码评审但要求高准确率的工程团队。
