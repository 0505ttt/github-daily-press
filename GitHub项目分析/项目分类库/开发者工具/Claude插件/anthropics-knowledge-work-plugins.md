## 详细介绍
Anthropic 面向 Claude Cowork（兼容 Claude Code）的官方插件市场仓库。每个插件按岗位职能打包四件套——技能、连接器、斜杠命令、子 Agent：销售（研究潜客、备战电话、写外联、做竞争战卡）、客服（分诊工单、起草回复、打包升级、沉淀知识库文章）、产品管理（写规格、排路线图、综合用户研究）、法务（合同审查、NDA 分诊、合规流程）、HR、数据分析（写 SQL、做仪表盘）等。所有组件都是纯文件（markdown + JSON），无代码、无基础设施、无构建步骤。设计定位是「可定制的起点」：改 .mcp.json 换成你自己的工具栈，往技能文件里塞公司术语、组织结构和流程，Claude 就成了懂你们公司的岗位专家。Claude Code 一条命令即可从该 marketplace 安装指定插件。

## 适用领域
用 Claude Cowork/Claude Code 的团队按岗位装配标准化工作流；想让 Claude 接入 Slack/Notion/Jira/HubSpot 等办公工具的知识工作者；研究 Agent 插件/技能打包结构（纯文件、无构建）的开发者。
