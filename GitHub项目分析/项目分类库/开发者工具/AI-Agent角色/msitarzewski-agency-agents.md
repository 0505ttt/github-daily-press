## 详细介绍
一个开源的 AI Agent 角色合集，每个 Agent 都是一个拥有独特人格、工作流程和交付物的专业角色。覆盖前端开发、社区运营、创意注入、现实校验等多个领域，旨在将 IDE 编程助手变成多角色 AI 代理团队。支持一键安装到 Claude Code、Cursor、Codex、Gemini、Osaurus 等主流工具，并提供原生桌面应用（macOS/Linux/Windows）浏览和安装。已有 14 万+ stars，Reddit 上引发大量讨论。

## 适用领域
使用 AI 编程工具的开发者、希望让 AI Agent 扮演不同专业角色的团队
