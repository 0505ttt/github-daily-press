## 详细介绍
holaOS 是一个开源的 All-in-One AI Agent 工作空间，核心理念是「The Computer for You and Your Agent」。它让你在同一个本地优先的工作空间中运行任意 Agent（Claude Code、Codex 或内置 holaOS Agent），跨你的工具、文件和应用，共享同一套记忆。核心差异化能力：一个共享记忆层（上下文、偏好、项目历史存储为本地纯文件，可读可编辑），所有 Agent 继承相同连接和技能；100+ 集成（Gmail、Notion、Slack、GitHub、Linear 等）一键 OAuth 连接；MCP 协议支持；HolaApps——安装的 App 作为真实交互界面（不只是聊天）与 Agent 并排运行；内置前沿模型（Kimi K3、GLM 5.2、GPT 5.6 等）或 BYOK；支持定时/触发器自动化。基于 Electron + TypeScript 构建。

## 适用领域
需要多 Agent 协同工作的开发者/团队、想统一管理 Claude Code / Codex 等编程 Agent 的用户、需要 Agent 跨工具操作的团队、对 AI 工作空间感兴趣的个人用户。
