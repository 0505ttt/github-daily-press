## 详细介绍
一个反直觉的 agent 行为约束技能：能不改就不改、能少写就少写，抑制 AI 过度工程的冲动。像给 agent 请了位奉行极简主义的老人带。适合被 agent 大改特改搞怕了的人。

## 适用领域
