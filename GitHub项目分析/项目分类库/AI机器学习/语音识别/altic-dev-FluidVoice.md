## 详细介绍
FluidVoice 是一款开源的 macOS 语音转文字听写应用，核心特色是所有 AI 处理完全在设备本地完成，无需云端、无需 API 密钥、数据不离开你的 Mac。1.6.0 版本引入了 "Fluid Intelligence"——一个完全本地运行的 AI 运行时，负责智能格式化、上下文感知大小写、后处理优化等。支持 NVIDIA Nemotron Speech 3.5、Parakeet Flash / v3 / v2、Cohere、Apple Speech、Whisper 等多种语音模型。作者将其定位为 Wispr Flow 的本地替代方案。通过 Homebrew 一键安装：`brew install --cask fluidvoice`。iOS 和 Windows 版本已开放候补名单。

## 适用领域
macOS 用户（特别是写作、编程、邮件场景）、注重隐私的用户（不想语音数据上传云端）、Wispr Flow 替代需求者、对本地 AI 语音技术感兴趣的开发者。
