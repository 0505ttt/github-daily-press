## 详细介绍
OpenAI Plugins 是 OpenAI 官方维护的插件体系仓库，定义了 ChatGPT 等大模型产品与外部服务（API）之间的连接规范。通过 OpenAPI 规范描述接口，让 AI 模型能够调用外部工具和数据源。虽然后续 ChatGPT 转向 GPT Store 和 Function Calling 方案，但插件规范的核心思想深刻影响了整个 AI Agent 生态。
