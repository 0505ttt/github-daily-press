## 详细介绍
一套面向 AI Agent 的 CAD 技能库，覆盖从模型生成到制造的完整工作流。核心能力包括：用自然语言或图片生成 STEP 格式 CAD 模型（可导出 STL / 3MF / GLB）、搜索现成零件（螺丝/轴承/电机）、创建 2D DXF 图纸、编写机器人 URDF / SRDF / SDF 描述文件、将网格切片为打印机可用的 G-code 并可直连 Bambu Lab 打印机。还支持在浏览器中预览 CAD 模型和 G-code。通过 Skills CLI 一键安装到 Claude Code 或 Codex。

## 适用领域
机械工程师、硬件设计师、机器人开发者、3D 打印爱好者、使用 AI Agent 辅助工程设计的团队
