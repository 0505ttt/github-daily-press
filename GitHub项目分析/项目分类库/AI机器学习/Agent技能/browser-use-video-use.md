## 详细介绍
browser-use 团队开源的「用编码 Agent 剪视频」技能包：原始素材丢进文件夹，在 Claude Code/Codex/Hermes 等任意有 shell 的 Agent 里说一句 edit these into a launch video，即得 edit/final.mp4。能力清单：自动剪掉口癖与废条、逐段自动调色、每个切点 30ms 音频淡入淡出防爆音、按风格烧字幕、经 HyperFrames/Remotion/Manim/PIL 生成动画叠层（并行子 Agent 各管一段）、渲染前在每个切点自检画面。会话记忆持久化在 project.md，下周继续剪能接上上周进度。安装是「一句话 setup prompt」——把安装指令贴给 Agent，它自己完成 clone、依赖、技能注册并向用户要 ElevenLabs API key。

## 适用领域
内容创作者与自媒体团队用对话式工作流剪口播、vlog、教程；Agent 开发者学习「技能包 + 自检 + 会话记忆」的工程范式；产品营销快速出片
