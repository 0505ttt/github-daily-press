## 详细介绍
Vibe-Trading 由香港大学数据科学实验室（HKUDS）开发，是一个开源的 AI 量化交易研究工作区。它将自然语言提示连接到市场数据加载、回测引擎、多 Agent 群体分析和交易日志等能力，支持 FastAPI 后端 + React 19 前端。核心功能包括：461 个学术因子库（Alpha Zoo）、5 种组合优化器、AST 加固的回测沙箱、策略开发生命周期管理（注册→监控→衰减→禁用）、MCP 协议集成、以及 Alpaca 等券商对接。项目刚于 7 月 13 日完成全部 10 项外部安全审计修复。

## 适用领域
量化交易研究员、金融数据分析师、AI Agent 开发者；需要将 LLM 能力引入交易策略研究流程的团队；学术研究中需要可复现的因子回测环境的研究者。
