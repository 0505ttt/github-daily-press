## 详细介绍
用自然语言对话就能下单的自主交易 agent：支持 Polymarket/Kalinka 预测市场、Solana DEX（经 Jupiter）、EVM 链（Uniswap V3/1inch）、Bittensor 挖矿和投资组合管理。内置 118+ 交易策略、鲸鱼追踪、套利检测、跟单和定投机器人。为 Colosseum Solana Agent 黑客松开发，12 天做出完整功能。自带 WebChat 界面（Claude 风格侧边栏、9 种语言、上下文自动压缩、无限历史记录），`npm install` 一条命令装好，`clodds onboard` 向导引导配置。

## 适用领域
加密量化爱好者、预测市场玩家；想参考"LLM+交易执行"完整架构（策略库/风控/多市场适配）的开发者；黑客松项目级别的快速交付范本
