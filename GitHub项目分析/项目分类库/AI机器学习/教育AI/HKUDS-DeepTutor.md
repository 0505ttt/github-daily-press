## 详细介绍
DeepTutor 由香港大学数据科学实验室（HKUDS）开发，是一个 Agent 原生的个性化学习工作台，将辅导、解题、测验生成、研究、可视化和掌握练习整合到一个可扩展的系统中。核心亮点：一个 Agent 运行时驱动所有模式（Chat/Quiz/Research/Visualize/Solve/Mastery Path）；多引擎知识库（LlamaIndex、PageIndex、GraphRAG、LightRAG、Obsidian）；三层可检视记忆系统（L1 事件追踪 / L2 表面摘要 / L3 跨面综合）；可连接外部 Agent（Claude Code、Codex、自定义 Partner）作为子代理协作；配套 CLI 和 SDK 支持 Agent 驱动。项目有配套 arXiv 论文，迭代非常活跃（v1.0 至 v1.5 仅用了约 3 个月）。

## 适用领域
学生、终身学习者、需要个性化辅导的自律型学习者；教育平台开发者、AI 辅导系统研究者；需要可自托管的 RAG+Agent 学习环境的教师和学校。
