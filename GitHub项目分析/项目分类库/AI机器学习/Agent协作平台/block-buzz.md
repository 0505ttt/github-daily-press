## 详细介绍
Buzz 由 Block 公司（原 Square）出品，定位为"蜂巢式（hive mind）协作平台"。底层本质是一个自托管的 Nostr relay：每条消息、反应、工作流步骤、代码评审、git 事件都是一条签名事件，人和 Agent 共享同一套身份模型与审计轨迹。外观像团队工作区，内核是事件日志。支持自建 relay，数据自主可控。区别于 Slack/Discord 的核心在于——Agent 是一等公民，与人类平权协作。

## 适用领域
希望让 AI Agent 深度融入团队协作流程的技术团队，重视数据主权、自托管需求，以及对人机协同工作流感兴趣的组织。
