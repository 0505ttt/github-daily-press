## 详细介绍
Hindsight 是 Vectorize 开源的 Agent 记忆系统，核心主张是「多数记忆系统只回放对话历史，Hindsight 让 Agent 学习」。架构上把记忆组织成四个逻辑网络——世界事实、Agent 经验、实体摘要、演化信念，再用 retain/recall/reflect 三个操作管理信息的写入、检索与更新；底层由时间感知的实体记忆层（Tempr）和反思推理层（Cara）组成，把对话流逐步转化为结构化、可查询的记忆库。在 LongMemEval 基准上，用开源 OSS-20B 骨干就把准确率从 39.0% 拉到 83.6%（+44.6 分），甚至超过全上下文 GPT-4o（60.2%）；换 Gemini-3 Pro 骨干达到 91.4%，是首个突破 90% 的 Agent 记忆系统，结果由弗吉尼亚理工与华盛顿邮报合作复现验证。接入成本低：LLM Wrapper 两行代码包裹现有模型即可，另有 MCP Server 模式和 Claude Code/Cursor 编码 Agent 文档技能，支持 Docker 自托管或 Python 嵌入式（免服务器）运行。与 Zep、Supermemory 等同类相比，区别在于用小得多的开源骨干即可打赢对方配 frontier 模型的成绩，且反思层可追溯地更新信念而非单纯堆向量。

## 适用领域
