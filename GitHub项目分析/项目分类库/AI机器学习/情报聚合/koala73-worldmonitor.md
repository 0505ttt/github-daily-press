## 详细介绍
聚合 500+ 新闻源跨 15 个分类，使用 AI 合成情报简报。配备双地图引擎（3D 地球 + WebGL 平面地图，56 种图层类型），支持跨流信号关联分析（军事、经济、灾害、升级信号汇合检测）。内置国家不稳定指数（CII）对 31 个 Tier-1 国家进行压力评分，覆盖 29 个证券交易所和加密货币的金融雷达。可完全本地运行（支持 Ollama），无需 API 密钥。从单一代码库生成 6 个站点变体（世界/科技/金融/商品/快乐/能源），同时提供 macOS / Windows / Linux 原生桌面应用（Tauri 2）。

地缘政治分析师、金融交易者、新闻工作者、需要实时全球态势感知的决策者、开源情报（OSINT）研究者
