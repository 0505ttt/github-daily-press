## 详细介绍
Paperclip 是一个开源的 AI Agent 编排平台（Node.js 服务端 + React UI），核心理念是把 AI Agent 当作"公司员工"来管理。它让你接入自己的 Agent（支持 OpenAI Codex、Claude、OpenClaw 等），为它们分配角色和目标，并像组织架构图一样编排协作。提供组织结构（org chart）、预算管控、治理规则（governance）和目标追踪——全部在一个部署内完成。支持自托管，官方定位为"零人公司"（zero-human company）的基础设施。7.6 万 stars 的体量使其成为 Agent 编排赛道最热门项目之一。与 AutoGPT 等自主 Agent 框架的区别：Paperclip 更强调组织化管理而非单个 Agent 的自主性。

## 适用领域
探索"零人公司/AI 员工"模式的创业者、需要多 Agent 协作完成业务流程的团队、AI 自动化运营爱好者、想要为 AI Agent 建立预算和治理体系的技术管理者。
