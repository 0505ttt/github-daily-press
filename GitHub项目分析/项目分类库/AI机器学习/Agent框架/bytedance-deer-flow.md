## 详细介绍
字节跳动出品的开源长程（long-horizon）SuperAgent 框架，已迭代至 2.0 版本。它能处理从几分钟到几小时不等的复杂任务，集成了沙箱、记忆、工具、技能、子 Agent 和消息网关六大核心能力。与只处理单轮对话的 Agent 不同，deer-flow 专注于需要多步骤、长时间执行的"长程任务"——如深度研究报告、大型代码库重构、持续创作。支持 Python 3.12 + Node.js 22 运行环境，提供中英日法俄多语言文档。78K+ stars 证明了它在开源 Agent 领域的超高人气。

## 适用领域
需要执行复杂多步骤任务的 AI 应用开发者、企业自动化工作流构建者、Agent 基础设施研究团队、深度研究/报告自动化场景。场景：自动化研究报告、长篇内容创作、复杂代码库分析、多 Agent 协作编排。
