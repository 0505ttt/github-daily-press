## 详细介绍
Agent-Native 是 BuilderIO 开源的 TypeScript 框架，用来构建"自主工作的 Agent + 专属 UI"配对的应用。核心设计是共享 action 层：每个能力用 `defineAction` 定义一次，Agent 把它当工具调用，UI 从代码里调用，两条路径共享同一套验证、权限和实现——Agent 不是去"点击 UI"，而是和 UI 走同一层。除共享 action 外还有共享数据（Agent 做的工作出现在 UI 里，UI 里的操作对 Agent 可见）和共享应用状态（Agent 能感知当前页面、选中记录等上下文）。框架内置认证与权限、技能与记忆、定时/事件驱动的自动化、多 Agent 协作，生产环境用 PostgreSQL、本地开发用 PGlite，自带你自己的 LLM 和数据库，所有构建产物归你。与通用 Agent 框架的区别在于它把"给知识工作一个像编程 Agent 那样有上下文、有预览、可检查可审批的环境"作为一等公民。

## 适用领域
适合构建带界面的 AI 应用（内部工具、客服台、运营面板、团队协作型 Agent 产品）的全栈/前端团队；解决"Agent 做完事用户看不见、用户改了 Agent 不知道"的双向割裂问题。
