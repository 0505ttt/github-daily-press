## 详细介绍
由 Google Labs 开发的 Agent Skills 模块库，专为 Stitch MCP 服务器设计。每个 Skill 遵循 Agent Skills 开放标准，可兼容 Antigravity、Gemini CLI、Claude Code、Cursor 等主流编码 Agent。项目覆盖 GitHub Issue 分拣、CI 工作流本地验证、Bug 修复等场景，代表了 Google 在「设计→代码」自动化方向的布局。近期 Google 举办了首届 Stitch Developer Week，MCP 生态和 Agent Skills 是核心议题。

## 适用领域
AI Agent 开发者、使用 Stitch/Gemini/Antigravity 的产品团队、关注设计到代码自动化的团队
