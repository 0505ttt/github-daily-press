## 详细介绍
RAGFlow 是一个领先的开源 RAG（检索增强生成）引擎，将前沿 RAG 技术与 Agent 能力融合，为 LLM 创建卓越的上下文层。核心功能包括：深度文档解析（支持 PDF、DOCX、PPTX 等复杂版式，精准识别表格、图片和布局）、基于模板的文本切片、混合检索（关键词+向量+知识图谱）、多路召回重排序、引用溯源。支持接入主流大模型（OpenAI、Claude、通义千问等），内置可视化 Agent 编排（工作流拖拽），可自托管。由 InfiniFlow 团队开发，已获近 8.8 万 stars，是开源 RAG 赛道的标杆项目。

## 适用领域
构建企业知识库问答系统的开发者、需要文档智能解析的团队、RAG 应用开发的工程师、希望自托管 RAG 服务的企业。
