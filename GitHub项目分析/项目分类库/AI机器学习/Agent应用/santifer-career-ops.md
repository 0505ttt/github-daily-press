## 详细介绍
career-ops 把 Claude Code 等 AI 编程 CLI 变成完整的求职流水线：自动扫描职位门户（Greenhouse、Ashby、Lever 及 150+ 公司官网），用结构化 A-F 评分表 + 五个加权维度给职位打 1.0-5.0 分（G 区块单独评估招聘信息合法性，不影响总分），再按职位描述生成 ATS 优化的定制 PDF 简历。它强调「过滤」而非海投——官方强烈建议低于 4.0 分别投，帮你在几百个职位里找出真正值得花时间的少数。Agent 用 Playwright 导航招聘页、通过理解简历与 JD 的语义匹配（而非关键词匹配）评估适配度，支持子 Agent 并行评估 10+ 职位，附带公司调研与关键联系人挖掘。作者用这套系统评估了 740+ 职位、生成 100+ 定制简历并成功拿到 Head of Applied AI 岗位，是「吃自家狗粮」的典范。

## 适用领域
求职者（尤其技术岗）系统化管理投递流水线、职业转型者需要 AI 评估匹配度、想学习 Agent 工作流编排（Playwright + 子 Agent + 结构化输出）的开发者。
