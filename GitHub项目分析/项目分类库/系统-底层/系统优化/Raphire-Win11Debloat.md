## 详细介绍
Win11Debloat 是一个轻量级 PowerShell 脚本，可快速精简和定制 Windows 体验。功能覆盖：移除预装臃肿应用、关闭遥测/诊断数据/活动历史/定向广告、禁用 Copilot 和 Windows Recall 等 AI 功能、恢复 Win10 风格右键菜单、自定义任务栏/开始菜单/文件管理器、关闭 Bing 搜索集成等。支持命令行参数自定义、Windows Audit 模式、以及对其他用户应用更改。所有操作均可轻松还原，移除的应用可通过 Microsoft Store 重新安装。一行 PowerShell 命令即可运行。

## 适用领域
Windows 系统管理员、追求系统纯净度的用户、IT 运维人员；批量部署 Windows 时需要标准化配置的场景；对新系统预装应用和遥测感到不满的普通用户。
