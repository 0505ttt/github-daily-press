## 详细介绍
RustDesk 是用 Rust 编写的开源远程桌面软件，定位为 TeamViewer/AnyDesk 的替代品。核心卖点是开箱即用零配置，同时数据完全自主：可以用官方 rendezvous/relay 服务器，也可以自建服务器，甚至参考开源 demo 自己写中继服务器，不用担心第三方窥探。客户端覆盖 Windows/Linux/macOS 桌面端（GUI 用 Flutter，旧版 Sciter 已弃用）和 Android/iOS 移动端（F-Droid 可下载），支持 Wayland。构建依赖 vcpkg 安装 libvpx、libyuv、opus、aom 等音视频编解码库。README 提供 26 种语言翻译，有活跃的 Discord/Reddit 社区，通过 Flathub 和 F-Droid 分发。

## 适用领域
需要远程技术支持的 IT 运维团队、重视数据主权想自建远程方案的企业、个人用户的跨设备远控场景、寻找 TeamViewer 商业授权替代品的中型团队。

## 背景调研
- **开发团队**：RustDesk 团队（rustdesk.com），项目创建于 2020 年 9 月，创始人 zhou（@rustdesk），社区贡献者众多
- **融资/商业化**：AGPL-3.0 开源协议 + 商业化 RustDesk Server Pro（付费自建服务器，提供高级特性：地址簿、Web 控制台、SSO 等）
