## 详细介绍
Windows Terminal 是微软开发的现代终端应用，集成了原 Windows 控制台主机（conhost）。支持多标签页、GPU 加速文本渲染、Unicode 和 CJK 字符、自定义主题和配色方案、可编程快捷键等现代终端特性。支持 PowerShell、CMD、WSL 等多种 Shell，是 Windows 平台开发者的标准终端工具。作为微软最受欢迎的开源项目之一，社区持续活跃迭代。

## 适用领域
Windows 平台开发者、系统管理员、所有需要在 Windows 上使用命令行的用户
