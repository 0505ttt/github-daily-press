## 详细介绍
Tinycast 是一个极小的 macOS 启动器：磁盘体积不到 3MB、内存占用 100MB 以内，用 SwiftUI 和 AppKit 原生构建，零第三方依赖、无 Electron、零遥测、无账号。功能覆盖一个热键调出应用模糊搜索、可搜索的剪贴板历史（文本+图片，直接贴回原应用）、内联计算器（数学/单位/实时汇率与加密货币换算）、Quicklinks（把 URL/搜索/文件/深链变成命令，支持占位符）、可复用 Markdown 片段模板、自定义 shell 命令绑定全局热键。最大亮点是能运行真正的 Raycast 扩展并以原生 SwiftUI 渲染，还支持直接读取 .rayconfig 导出文件一键迁移快捷键/片段/配置。与 Raycast/Alfred 相比走的是「免费开源 + 本地优先 + 无订阅」路线。

## 适用领域
嫌 Raycast 重、不想付费订阅的 Mac 用户；重视隐私（零遥测无账号）的用户；想从 Raycast 无痛迁移配置的效率工具玩家。
