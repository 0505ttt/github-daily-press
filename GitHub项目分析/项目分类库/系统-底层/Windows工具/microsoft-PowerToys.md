## 详细介绍
Microsoft PowerToys 是一组免费的系统实用工具集，为 Windows 高级用户提供强大的生产力增强和自定义功能。包含 20+ 个工具：PowerToys Run（快速启动器，类似 Alfred/Raycast）、FancyZones（窗口管理器，自定义分屏布局）、ColorPicker（屏幕取色）、Keyboard Manager（键位重映射）、PowerRename（批量重命名）、File Explorer Add-ons（预览 SVG/Markdown）、Always On Top（窗口置顶）、Text Extractor（OCR 文字提取）等。采用 WinUI 3 / WPF 技术栈，支持 Windows 10/11。与第三方工具拼凑相比，PowerToys 由微软官方维护、质量有保障、更新频繁。

## 适用领域
Windows 高级用户、追求效率的开发者/设计师/运营人员、需要窗口管理和快捷操作的用户、从 macOS 迁移到 Windows 的用户（替代 Alfred/Raycast）。
