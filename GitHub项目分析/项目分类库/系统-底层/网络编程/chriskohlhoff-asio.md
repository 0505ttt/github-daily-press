## 详细介绍
Asio 是一个跨平台的 C++ 库，用于网络和底层 I/O 编程，采用 Proactor 模式实现异步操作。它是 C++ 网络编程领域的事实标准，Boost.Asio 的独立版本。支持 TCP/UDP、SSL、定时器、串口等，C++20 协程支持完善。大量高性能网络框架（如 cpp-httplib、websocketpp）基于 Asio 构建。
