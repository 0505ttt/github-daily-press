## 详细介绍
ChinaTextbook 收集了中国小学、初中（含五四学制）、高中、大学全学段的官方 PDF 教材，总库超过 110GB。项目发起初衷是"反对有人把免费教材加水印在某站贩卖牟利"，将这些资源集中开源，促进义务教育普及和消除地区间教育差距，同时也方便海外华人子女继续接触国内教育体系。内容涵盖各学段的语文、数学、英语等科目，大学部分包含高等数学、线性代数、离散数学、概率论等。由于 GitHub 单文件 100MB 限制，大文件被拆分为 35MB 分片，需用配套的合并工具（tchMaterial-parser）拼接。

## 适用领域
学生、家长、教师；需要查阅/下载国内教材的自学者；海外华人家庭（让子女接触国内教育内容）；教育公益组织和偏远地区学习者；需要教材语料做 NLP/教育研究的开发者。场景：离线学习、备课参考、教育公平促进、数据集构建。
