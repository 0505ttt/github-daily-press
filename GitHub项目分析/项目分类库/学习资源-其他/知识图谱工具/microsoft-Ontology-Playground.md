## 详细介绍
微软出品的免费开源 Web 应用，用于学习本体论（Ontology）和 Microsoft Fabric IQ。可以探索预构建本体目录，可视化设计自己的本体，导出为 RDF/XML 格式，并分享交互式图表。零后端、完全静态部署，降低了知识图谱和语义网技术的学习门槛。
