## 详细介绍
这是 GitHub 上星标数最高的计算机科学类项目之一（36 万+ 星），用一套循序渐进的结构讲解分布式系统设计：CAP 定理、一致性、可用性、分区容错、负载均衡、缓存、分片、消息队列、CDN、数据库选型等。每个主题都配有真实面试题与参考答案（如设计 Twitter、设计短链、设计 KV 存储），并提供 Anki 抽认卡帮助记忆。它不是某一门语言或框架的教程，而是面向架构能力的知识体系，长期是大厂系统设计面试的事实标准复习材料。
