## 详细介绍
一个维护全球公开可用 IPTV（网络电视）频道的开源项目，收录了来自世界各地的数千个免费直播频道。所有频道链接经过社区验证，按国家、语言、类别分类整理，提供 M3U 播放列表可直接导入播放器使用。由 freearhey 等核心贡献者维护，iptv-bot 自动化更新，是 GitHub 上 star 数最高的媒体资源项目之一。

## 适用领域
IPTV 用户、需要全球频道资源的用户、媒体播放器用户
