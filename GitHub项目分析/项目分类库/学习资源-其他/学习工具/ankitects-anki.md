## 详细介绍
Anki 是间隔重复（spaced repetition）记忆法的标杆软件：按遗忘曲线安排每张卡片的复习时机，你已经会的少出现、难的多出现，把记忆效率最大化。本仓库是桌面版源码，后端已用 Rust 重写，前端基于 Qt，支持多平台与 AnkiWeb 同步。核心能力包括高度可定制的卡片模板（HTML/CSS/JS）、数千个共享插件生态、学习统计图表，以及可选的新一代 FSRS 调度算法。与 Quizlet/Brainscape 等商业产品相比，它完全免费开源、数据自主可导出，二十年积累的共享牌组社区是最大护城河。2026 年各家「最佳间隔重复应用」评测中仍稳居第一梯队。

## 适用领域
语言学习、医考/法考/考证等大量记忆型备考、任何需要把知识长期记住的学习者；对记忆算法（SM-2/FSRS）与 Rust 桌面应用工程感兴趣的开发者。
