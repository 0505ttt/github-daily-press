## 详细介绍
微软出品、Star 总数超 11 万的重量级课程，已迭代到 Version 3。21 节课覆盖生成式 AI 全栈：从 LLM 原理、Prompt Engineering、RAG 与向量数据库，到 AI Agents、微调、SLM，再到 Mistral 和 Meta 系列模型实战。每节课配有视频讲解 + Python/TypeScript 双语言代码 + Azure OpenAI / OpenAI / Foundry Local 三种运行环境。还提供 50+ 种语言的自动翻译版本。这是目前体系最完整的 GenAI 实战课程之一。

## 适用领域
想入门生成式 AI 应用开发的全栈工程师、产品经理需要理解技术边界者、高校教学、企业内训。场景：构建 RAG 系统、聊天应用、图像生成应用，学习 LLMOps 全流程。
