## 详细介绍
Manim 是由著名数学科普 YouTuber 3Blue1Brown（Grant Sanderson）开发的程序化数学动画引擎，专门用于创建精确的解释性数学视频。它通过 Python 代码定义数学对象和动画，渲染出高质量的教学动画——从函数图像变换到几何证明，从线性代数到微积分概念。核心技术亮点：纯 Python 接口，支持 OpenGL 渲染、FFmpeg 视频输出和 LaTeX 公式排版。注意有两个版本：此仓库（ManimGL）是 3b1b 个人原始版本；2020 年社区 fork 出 Manim Community Edition（更稳定、更易上手）。Manim 通过代码精确控制动画的每一步，与 After Effects 等手动动画工具完全不同，特别适合需要数学精度的可视化内容。MIT 许可证，已有中文文档社区（manim-kindergarten）维护翻译。
