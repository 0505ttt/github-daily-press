## 详细介绍
Chat2DB 是一款 AI 驱动的跨平台数据库客户端，支持 MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、MongoDB、Redis、SQLite、MariaDB、TiDB、Hive、DB2、Snowflake、BigQuery 等 30+ 种数据库。核心功能包括：完整的 SQL 工作区（编辑、补全、格式化、执行、历史记录）、AI 助手（自然语言生成/解释/优化 SQL，支持接入自有 AI 模型）、可视化数据管理（表结构 DDL/DML、原地编辑数据）、数据导入导出、仪表盘和图表、ER 图、开源 CLI 带 MCP 支持。安全方面使用 AES-256-GCM 加密存储数据源密码和 AI API 密钥。社区版完全免费，桌面应用支持 Windows/macOS/Linux，也可通过 Docker 部署 Web 版。

## 适用领域
需要管理多种数据库的 DBA、数据分析师、后端开发者、需要 AI 辅助编写和优化 SQL 的数据团队、从 Navicat/DBeaver 迁移的用户
