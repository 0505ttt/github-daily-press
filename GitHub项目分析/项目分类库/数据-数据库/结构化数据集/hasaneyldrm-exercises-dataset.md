## 详细介绍
这是一个包含 1,324 个健身动作的结构化数据集，提供肌肉群、器械、目标肌群分类数据，以及 6 种语言（英语、西班牙语、意大利语、土耳其语、俄语、中文）的分步指导。数据源自 ExerciseDB v1，本仓库在此基础上添加了多语言翻译和交互式浏览器。附带 setup.html 开发者向导，可一键生成 SQL Server/PostgreSQL/MySQL/SQLite 的建表语句和 INSERT 语句，并提供 JS/Python/C#/Java/PHP/Go/cURL 的 API 调用示例。还支持将结构化 Prompt 粘贴到 LLM 生成完整 REST API。注意：动作的图片和 GIF 动画因版权争议不包含在仓库中。

## 适用领域
健身/运动 App 开发者、健康领域产品经理；需要运动数据的 ML 研究者；健身教育平台的内容团队；需要快速搭建健身应用后端的独立开发者。
