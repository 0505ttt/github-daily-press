## 详细介绍
MediaCrawler 是一个功能强大的多平台自媒体数据采集工具，支持小红书、抖音、快手、B站、微博、百度贴吧、知乎七大主流平台的公开信息抓取，涵盖笔记/视频/帖子内容及其评论（含二级评论）。核心技术原理基于 Playwright 浏览器自动化框架登录并保存登录态，利用浏览器上下文通过 JS 表达式获取签名参数，无需逆向复杂加密算法即可绕过平台反爬。支持关键词搜索、指定帖子ID爬取、指定创作者主页、IP代理池、登录态缓存、生成评论词云图等功能，提供 WebUI 可视化界面和 PostgreSQL 持久化存储。与传统爬虫框架相比，其最大优势是大幅降低了技术门槛——无需逆向即可采集数据。

## 适用领域
社交媒体数据分析师、舆情监控团队、市场研究人员、NLP/推荐系统数据准备者；需要多平台公开内容批量采集的场景（仅限学习研究用途）。
