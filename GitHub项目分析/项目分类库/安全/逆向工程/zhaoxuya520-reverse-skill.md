## 详细介绍
当 AI Agent（Claude Code、Codex CLI、Cursor 等）遇到 APK、二进制文件、前端 JS 加密、CTF 题目或渗透测试目标时，这个包会自动将其路由到正确的方法论，检查可用工具并执行可重复的工作流，而不是靠猜测命令来应对。核心设计是"AI 自动路由 + 按需自举工具链 + 自动进化经验库"，涵盖 APK 逆向、iOS 移动分析、二进制逆向（IDA/radare2/Ghidra）、JS 逆向、恶意软件分析、渗透测试、CTF 编排（40+ 子技能）等 15+ 个场景。与同类通用 Skill 包的区别在于，它内置了完整的路由矩阵（MASTER-ROUTING），能根据目标类型自动选择 jadx、apktool、Frida、IDA 或 BurpSuite 等工具，并通过经验回写机制让经验库持续进化。

## 适用领域
逆向工程师、安全研究员、渗透测试人员、CTF 选手、使用 Claude Code / Kiro / Cursor / Cline 等 AI 编程客户端的安全从业者。
