## 详细介绍
一份持续更新的 Linux 服务器安全加固指南，目标是既教你怎么做，也解释为什么这么做。从 SSH 安全配置（公私钥、2FA/MFA、Diffie-Hellman 密钥）、基础安全（sudo/su 权限控制、防火墙规则）到应用层安全和网络监控，覆盖服务器安全加固全链路。每个配置项都附带原理解释而非简单罗列步骤，帮助读者理解安全措施的本质。提供 Ansible Playbooks 支持自动化部署，适合批量服务器管理。采用 CC-BY-SA 许可证，鼓励社区贡献和二次传播。适合从入门到中级水平的 Linux 管理员系统学习安全知识。

## 适用领域
自建 VPS/云服务器的个人开发者与独立站长（上手即用的加固清单）；入门到中级 Linux 运维/安全工程师（知其所以然的学习材料）；用 Ansible 做批量服务器安全基线管理的运维团队。
