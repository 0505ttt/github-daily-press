## 详细介绍
微软开源的 AI Agent 治理框架（AGT），为自主 AI Agent 提供策略执行、零信任身份认证、执行沙箱和可靠性工程。它是业界首个覆盖 OWASP Agentic AI Top 10 全部 10 项风险的开源工具包，通过确定性的亚毫秒级策略引擎在每次 Agent 行动前进行拦截和验证。支持 .NET 集成，可在 MCP 工具调用层面进行治理。MIT 许可证，定位为企业级 AI Agent 安全基础设施，被社区称为「AI Agent 的操作系统级安全层」。

## 适用领域
部署自主 AI Agent 的企业安全团队、需要合规治理 AI Agent 行为的架构师、关注 AI 安全的研究者和工程师。
