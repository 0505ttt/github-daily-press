## 详细介绍
authentik 是一个用 Python/Django 编写的开源身份提供者（Identity Provider）和访问管理平台，2020 年由 Jens Langhammer 创建。它支持 OAuth2/OIDC、SAML、LDAP、RADIUS、SCIM 等几乎所有主流认证协议，可作为自托管方案替代 Okta、Auth0 等商业产品。核心特色是"Flows"——一套可视化的可组合认证流程构建器，让管理员像搭积木一样自定义登录、注册、密码重置等流程，支持多因素认证（MFA）、条件策略和社交登录。当前最新版本为 2026.11，正在引入 Rust worker 提升性能，企业版还支持 SAML 1.1 等高级特性。

## 适用领域
需要自托管 SSO（单点登录）的中小型企业、运维团队和开发者；想脱离 Okta/Auth0 商业锁定的组织；为内部应用、Homelab 或自部署服务（如 Grafana、Nextcloud）统一对接身份认证的玩家；需要灵活定制认证流程（多因素、社交登录、LDAP 联动）的技术团队。
