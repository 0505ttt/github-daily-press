## 详细介绍
客户端跑 SOCKS5 代理，出口节点负责拆包转发；巧在"可插拔传输层"设计——目前有两种：把 TCP 报文伪装成 Yandex Docs 文档光标消息传输，或走 WebRTC DataChannel（MAX）。出口节点的 TCP 连接跑在 gvisor 用户态协议栈里，内核不持有 socket，因此需要精确抑制 RST 包防止隧道被拆。覆盖桌面/iOS/Android 三端客户端，Go 编写。作者声明项目完全非商业、不鼓励用于绕过任何限制。

## 适用领域
网络协议与审查技术研究者在研究流量伪装架构（把任意 TCP 流量嵌进合法应用信道的通用框架）；需要理解 gvisor 用户态网络栈落地方式的开发者

## 背景调研
