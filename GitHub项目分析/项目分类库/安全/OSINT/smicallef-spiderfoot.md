## 详细介绍
SpiderFoot 是一个成熟的开源情报（OSINT）自动化工具，自 2012 年持续开发至今，已集成超过 200 个模块/数据源。它通过内置 Web 服务器提供直观的 Web 界面，也支持完全的命令行操作。核心功能包括：YAML 可配置的关联引擎（37 条预定义规则）、CSV/JSON/GEXF 导出、API 密钥导入导出、SQLite 后端自定义查询、TOR 集成（暗网搜索）、可视化图表、Docker 部署。还能调用 DNSTwist、Whatweb、Nmap、CMSeeK 等外部工具。商业化版本 SpiderFoot HX 提供云端托管、攻击面监控、多用户协作等高级功能。

## 适用领域
安全分析师和威胁情报团队、红队/渗透测试工程师、企业攻击面管理、安全合规审计、OSINT 研究者。
