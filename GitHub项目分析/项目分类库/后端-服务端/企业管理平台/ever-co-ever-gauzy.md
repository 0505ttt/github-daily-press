## 详细介绍
Ever® Gauzy™ 把企业资源计划（ERP）、客户关系管理（CRM）、人力资源管理（HRM）、招聘跟踪（ATS）、项目与工时管理（PM）装进同一个平台，还覆盖销售管道、提案、开票计费、库存与供应链、多组织管理等场景。提供 Headless API（api.gauzy.co/docs），前端界面与 API 解耦，方便二次开发。采用 AGPL v3 协议，由 ever-co 公司持续维护，同团队还开源了 Ever Teams 协作平台和刚发布的 Ever Works 自主 Agent 运行时。与 Odoo 等重型 ERP 相比，它走的是「现代 TypeScript 技术栈 + Headless API」路线，部署和二次开发门槛更低。

## 适用领域
想用开源替代 SAP/Odoo/HubSpot 组合的中小企业；要求业务数据自托管的团队；需要一体化后台系统做二次开发起步的创业团队。
