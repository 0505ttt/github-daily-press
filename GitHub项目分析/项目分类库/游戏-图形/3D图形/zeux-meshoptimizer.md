## 详细介绍
meshoptimizer 是一个 C++ 网格（3D Mesh）优化库，提供顶点缓存优化、Overdraw 优化、简化（Simplification）、网格压缩等核心功能。支持 glTF 标准，被 Roblox、EA 等游戏公司采用。库本身仅依赖 C++ 标准库，可轻松集成到现有引擎中。作者 Zeux 是 Roblox 引擎团队的核心成员，该库在工业界验证充分。
