## 详细介绍
Unturned 是一款免费的开放世界僵尸生存沙盒游戏，在 Steam 上拥有大量玩家基础。本次开源包含基于 Unity 2022.3.62f3 的完整游戏源代码，社区可直接 clone 仓库、用 Unity 编辑器打开项目进行修改和二次开发。项目包含游戏启动场景、模组支持文档和 YouTube 开发教程等资源。对于独立游戏开发者和 Unity 学习者来说，这是一份难得的「商业级生存游戏」参考素材，涵盖开放世界、多人联网、物品系统等核心机制。

## 适用领域
独立游戏开发者与 Unity 学习者（商业级完整项目参考）；Unturned Mod 制作者与服务器管理员（total conversion 级二次开发）；研究开放世界/多人联网游戏机制实现的游戏专业学生。
