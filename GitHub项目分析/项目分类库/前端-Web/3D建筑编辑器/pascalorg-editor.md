## 详细介绍
Pascal Editor 是一个完全在浏览器中运行的 3D 建筑设计工具，使用 React Three Fiber + WebGPU 实现 GPU 级渲染速度，即使五年前的笔记本也能流畅运行。采用 Turborepo monorepo 架构，分离为 core（场景状态）、viewer（3D 渲染运行时）、editor（编辑工具）、nodes（内置节点定义）四个包，职责清晰。支持楼层平面图绘制、门窗放置、区域标注等完整建筑设计流程，并通过 IndexedDB 持久化场景数据、Zundo 实现撤销/重做。与专业 3D 建模软件相比，它零安装、即开即用，数据完全本地化。

## 适用领域
建筑师、室内设计师、3D 建模爱好者；需要在浏览器中快速创建和分享建筑方案的用户；对 WebGPU/React Three Fiber 感兴趣的前端开发者。
