## 详细介绍
Bun 是一个基于 JavaScriptCore（Safari 的 JS 引擎）的 JavaScript 运行时，用 Rust 编写，旨在替代 Node.js + npm + webpack + jest 的组合。启动速度比 Node.js 快 4 倍，包安装速度比 npm 快 25 倍。内置 TypeScript/JSX 转译、SQLite、WebSocket 等功能，零配置开箱即用。2023 年发布 1.0 后持续高速迭代，目前 94k+ stars 是 JS 生态最热门项目之一。

## 适用领域
前端/全栈开发者、Node.js 替代方案探索者、追求极致构建速度的团队
