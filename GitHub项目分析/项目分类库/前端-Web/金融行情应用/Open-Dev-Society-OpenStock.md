## 详细介绍
OpenStock 是 Open Dev Society 社区出品的开源股票行情应用，主打实时价格追踪、个性化提醒和公司详情洞察，宣言是"为所有人构建、永远免费"。技术栈为现代全栈组合：Next.js 15（App Router）+ React 19 + Tailwind CSS v4 + shadcn/ui，认证用 Better Auth，MongoDB 持久化，行情数据来自 Finnhub，图表和市场视图用 TradingView 组件，支持 Docker 一键部署。它与收费行情平台的区别在于完全开放源码（AGPL-3.0）、无订阅无 Pro 墙，且项目特别鸣谢了 Adrian Hajdin（JavaScript Mastery）的行情应用教程作为起点。注意它不是券商，行情可能有延迟，也不构成投资建议。

## 适用领域
个人投资者和想自托管行情面板的散户/小团队；也适合前端学习者研究一个完整的现代 Next.js 全栈实战项目；解决"不想为实时行情和提醒功能付订阅费"的需求。
