## 详细介绍
Diagram Design 是一个专为 Claude Code、Codex 和 Pi 设计的 Agent 技能，提供 27+ 种编辑级图表类型（架构图、流程图、时序图、状态机、ER 图、时间线、泳道图、四象限等）。每种图表都提供极简浅色、极简深色、完整编辑三种变体，输出为自包含的 HTML+SVG 文件——无 JS 依赖、无外部图片，浏览器直接打开。核心亮点：60 秒读取你的网站品牌色和字体并应用到所有图表，还能导入 draw.io 或 Mermaid 源文件重绘。作者定位明确："没有 Figma，没有通用圆角框，没有 30 分钟调色"。

## 适用领域
内容创作者、技术博主、使用 Claude Code / Codex 的开发者——需要高质量技术图表又不想跟 Figma 较劲的场景。
