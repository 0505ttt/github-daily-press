## 详细介绍
由 Andrew Rabert 开发的 Jellyfin 桌面客户端，原名 Jellyfin Desktop。作者从 Jellyfin 官方团队独立后，将 V3 版本更名为 Jellium Desktop 继续独立开发。基于 Rust 构建，提供原生桌面体验，支持 Jellyfin 媒体服务器的完整功能。由于已非官方项目，社区正在讨论新的品牌定位和命名。

## 适用领域
Jellyfin 媒体服务器用户、需要原生桌面客户端的家庭媒体中心搭建者
