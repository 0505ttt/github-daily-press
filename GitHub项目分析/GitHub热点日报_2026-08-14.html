Claude Code 的编辑级图表技能——29 种图表类型，自包含 HTML+SVG，告别 Mermaid 模板

Diagram Design 是一个专为 Claude Code、Codex 和 Pi 设计的 Agent 技能，提供 29 种编辑级图表类型（架构图、流程图、时序图、状态机、ER 图、时间线、泳道图等）。每种图表都提供极简浅色、极简深色、完整编辑三种变体，输出为自包含的 HTML+SVG 文件——无 JS 依赖、无外部图片，浏览器直接打开。核心亮点：60 秒读取你的网站品牌色和字体并应用到所有图表，还能导入 draw.io 或 Mermaid 源文件重绘。作者定位明确：「没有 Figma，没有通用圆角框，没有 30 分钟调色」。

适用领域：内容创作者、技术博主、使用 Claude Code / Codex 的开发者——需要高质量技术图表又不想跟 Figma 较劲的场景。

知识归类：C-前端/Web › SVG图表 › AI生成技能

⭐ 总计 6,568 今日 +727 Fork 692
图原生的 AI 上下文基础设施——为 AI 系统提供结构化上下文、因果推理和完整决策溯源

Semantica 是一个开源的图原生（Graph-Native）基础设施层，解决 AI Agent 缺乏结构化上下文和决策可审计性的问题。它通过知识图谱摄入企业数据，自动提取实体、关系和语义信息，构建可查询的上下文图谱（Context Graph）。核心能力包括：为 LLM/Agent 提供可追溯的推理路径（provenance）、支持因果推理和语义搜索、内置本体（ontology）引擎让数据具有语义层。与传统向量数据库 RAG 的区别在于：Semantica 用图谱关系而非向量相似度做检索，决策过程可解释、可审计。

适用领域：需要可解释 AI 决策的企业团队、构建 Agent 的开发者（需要给 Agent 提供结构化知识上下文）、知识图谱/语义搜索方向的工程师、需要决策溯源与合规审计的金融/法律/医疗场景。

知识归类：A-AI/机器学习 › 知识图谱 › Agent上下文基础设施

cactus-compute/needle 🆕 新上榜
Python
⭐ 总计 4,917 今日 +768 Fork 332
14MB 超微基础模型——为手机、穿戴设备、智能家居和机器人打造的工具调用引擎

Needle 2 是一个开源的 4500 万参数模型，专为工具调用（tool calling）、设备使用和结构化提取设计。整个模型打包成单个 14MB 二进制文件，完整会话仅需约 28MB 内存。它基于 Cactus Compute 的 Simple Attention Network 研究成果，采用 CQ2-bit 量化压缩并内置推理引擎。在基准测试中，Needle 2 与 FunctionGemma 270M、LFM2.5 230M 等模型互有胜负，但体积小 5-70 倍。核心特色：权重烧入引擎（无需单独模型文件）、置信度门控（每个响应携带校准置信分数）、工具检索（声明大型工具目录后自动检索 Top 5）、256 token 滑动窗口确保内存恒定在 28MB。通过 pip install cactus-needle 即可使用。

适用领域：嵌入式 AI 开发者、物联网/可穿戴设备工程师、需要在边缘设备上运行工具调用的团队、机器人开发者、对超小型模型推理感兴趣的研究人员。

知识归类：A-AI/机器学习 › 边缘AI › 超小模型

macOS 最快的本地 AI 听写应用——完全在设备上运行 STT + 自训练增强模型

FluidVoice 是一款开源的 macOS 语音转文字听写应用，核心特色是所有 AI 处理完全在设备本地完成，无需云端、无需 API 密钥、数据不离开你的 Mac。1.6.0 版本引入了 "Fluid Intelligence"——一个完全本地运行的 AI 运行时，负责智能格式化、上下文感知大小写、后处理优化等。支持 NVIDIA Nemotron Speech 3.5、Parakeet Flash / v3 / v2、Cohere、Apple Speech、Whisper 等多种语音模型。作者将其定位为 Wispr Flow 的本地替代方案。通过 Homebrew 一键安装：brew install --cask fluidvoice。iOS 和 Windows 版本已开放候补名单。

适用领域：macOS 用户（特别是写作、编程、邮件场景）、注重隐私的用户（不想语音数据上传云端）、Wispr Flow 替代需求者、对本地 AI 语音技术感兴趣的开发者。

⭐ 总计 12,389 今日 +166 Fork 1,667
邮箱注册检测工具——检查邮箱在 Twitter、Instagram 等 120+ 网站是否已注册

Holehe 是一个经典的 OSINT（开源情报）工具，通过网站的「忘记密码」功能检查一个邮箱地址是否在 Twitter、Instagram、Imgur 等 120+ 网站上注册了账号。核心原理是利用密码重置流程的信息差异来判断邮箱是否关联了账号，整个过程不会向目标邮箱发送任何邮件（不会惊动被调查者）。支持命令行（holehe test@gmail.com）和 Python 库两种使用方式，也可通过 Docker 部署。已有商业化在线版本 osint.industries。该项目自 2020 年开源，使用 Trio 异步框架并行检测。

适用领域：OSINT 调查人员、安全研究人员、渗透测试工程师、私家调查员、需要做邮箱归属分析的安全团队。

OSINT 自动化引擎——集成 200+ 数据源，自动化威胁情报和攻击面映射

SpiderFoot 是一个成熟的开源情报（OSINT）自动化工具，自 2012 年持续开发至今，已集成超过 200 个模块/数据源。它通过内置 Web 服务器提供直观的 Web 界面，也支持完全的命令行操作。核心功能包括：YAML 可配置的关联引擎（37 条预定义规则）、CSV/JSON/GEXF 导出、API 密钥导入导出、SQLite 后端自定义查询、TOR 集成（暗网搜索）、可视化图表、Docker 部署。还能调用 DNSTwist、Whatweb、Nmap、CMSeeK 等外部工具。商业化版本 SpiderFoot HX 提供云端托管、攻击面监控、多用户协作等高级功能。

适用领域：安全分析师和威胁情报团队、红队/渗透测试工程师、企业攻击面管理、安全合规审计、OSINT 研究者。

⭐ 总计 1,182 今日 +408 Fork 105
NVIDIA 出品的 LLM 流量代理——让 Claude Code / Codex 无缝对接开源模型

Switchyard 是 NVIDIA NeMo 团队推出的 Rust 代理和库，专为 LLM 流量路由设计。核心能力是协议翻译：在 OpenAI Chat、Anthropic Messages 和 OpenAI Responses 三种 API 格式之间自动转换，让 Claude Code 或 Codex 等编程 Agent 继续说它们的「母语 API」，而后端实际由 vLLM、NVIDIA NIM、Ollama 或任何 OpenAI 兼容端点提供服务。支持多后端路由（随机路由、LLM 分类器路由、信号驱动的阶段路由器、自定义算法）、Prometheus 运维指标（请求、错误、延迟、token 用量、路由开销全覆盖）。一条命令即可启动：switchyard launch claude --model switchyard。

适用领域：使用 Claude Code / Codex 但想接入开源模型的开发者、需要 LLM 流量路由和 A/B 基准测试的工程团队、NVIDIA NIM / vLLM 用户。
