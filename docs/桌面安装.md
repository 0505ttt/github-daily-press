# 桌面安装与独立窗口

普通读者可以直接打开[在线杂志](https://0505ttt.github.io/github-daily-press/)。需要桌面图标、独立窗口或自己的模型设置时，再下载桌面包。

## 下载哪一个

在 [GitHub Releases](https://github.com/0505ttt/github-daily-press/releases) 的附件中选择对应文件：

| 系统 | 文件 | 使用方法 |
| --- | --- | --- |
| Apple 芯片 Mac | `GitHubDailyPress-1.0.0-macos-arm64.dmg` | 打开磁盘映像，将应用拖到“应用程序” |
| Intel Mac | `GitHubDailyPress-1.0.0-macos-x64.dmg` | 打开磁盘映像，将应用拖到“应用程序” |
| Windows 10/11 64 位 | `GitHubDailyPress-1.0.0-windows-x64-setup.exe` | 运行安装向导，开始菜单打开应用 |
| Windows 便携版 | `GitHubDailyPress-1.0.0-windows-x64-portable.zip` | 完整解压，运行其中的 `GitHubDailyPress.exe` |

桌面包已经包含 Python 和本项目依赖，不需要另外安装 Python、运行命令或先打开浏览器。源码 ZIP 用于开发与自己部署，不能当作上述桌面安装包。

桌面安装从空白资料库开始，不附带作者的公开日报、档案或 AI 资讯，也不会默认同步作者仓库。第一次成功生成自己的日报就是第 001 期，以后按自己积累的有效日报递增；重启和升级不会清零。只想阅读作者每天更新的内容，直接打开上面的在线杂志即可。

自己采编可以配置第三方接口或本地模型，也可以让现有 AI 工具按项目规范生成资料。已有模型配置会保留，不会被安装器覆盖。

## 系统提示

- Windows 使用 Microsoft Edge WebView2 Runtime。Windows 11 通常已经包含；若安装器提示缺少，请按提示到 [Microsoft 官方网站](https://developer.microsoft.com/microsoft-edge/webview2/) 安装运行时，再安装应用。便携版同样需要该运行时。
- 当前构建没有开发者付费证书签名或 Apple 公证。系统可能提示开发者身份无法验证；仅在确认下载自本仓库并核对 `.sha256` 后，按系统针对单个应用的放行操作处理。不要关闭系统整体安全保护。
- Mac 的最低系统版本由所用构建系统决定；发布时应以该版本实际验证范围为准。不同架构分别提供包，不把单架构包标成通用版本。

## 打开和关闭

应用会自己启动 `http://127.0.0.1:8765/` 本机服务，并在独立窗口显示杂志，没有地址栏、标签页和书签栏。默认最大化，可以使用系统全屏操作。

关闭应用窗口会停止它自己启动的服务。再次双击图标即可重新启动，自己已经生成的内容在断网时也能阅读。首次尚未生成日报时显示空白引导，不使用作者历史填充。

如果提示端口 8765 被占用，先退出另一份本应用或命令行阅读服务，再重新打开。应用不会接管其他程序的端口。再次启动同一桌面程序时，会提示返回已打开的窗口。

## 数据与升级

应用程序文件、阅读数据和密钥分别存放。安装器不会把配置或密钥放进公开页面；模型配置继续使用本项目用户配置目录。

阅读数据在系统用户数据目录中的 `GitHubDailyPress/workspace` 保存，浏览缓存单独保存。卸载应用或把 Mac 应用移到废纸篓，不自动删除自己的报告和模型配置。

如主动配置阅读来源仓库，同步只更新阅读数据。应用程序的新版本通过重新下载和安装更新，当前没有自动下载、替换二进制程序的功能。新安装包更新网页资源和构建脚本，已有同名日报及项目档案保留用户版本。

## 从源码构建桌面包

在对应的 Mac 或 Windows 系统中，先按 README 安装本项目，然后运行：

```console
python -m pip install -e . -r requirements-desktop.txt
python tools/package_desktop.py
```

Windows 额外安装 Inno Setup 6，并使 `ISCC.exe` 位于默认安装位置或 `PATH` 中。产物位于 `.runtime/desktop/artifacts/`；构建日志、自检报告及临时工作目录不会上传为阅读内容。

每个冻结包都运行种子哈希、可写目录和实际回环 HTTP 自检。GitHub Actions 对 Mac arm64、Mac x64 和 Windows x64 分别构建；这些自检不能替代各平台的实际安装和窗口交互验证。
