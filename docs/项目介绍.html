从本地开始，用三个步骤打开。

1

准备并启动

安装 Python 3.11+，下载项目。Mac 运行 启动.command，Windows 运行 启动.bat。首次安装依赖需要联网。

2

安装为应用

Chrome 或 Edge 打开 http://127.0.0.1:8765/，选择安装，之后从系统应用图标进入独立窗口。

3

缓存后继续读

等待“可离线阅读”。需要设置模型、生成或同步内容时，再启动本地服务。

独立窗口没有地址栏、标签页和书签栏；“全屏阅读”可进一步铺满画面。应用图标本身不负责启动 Python 服务。
