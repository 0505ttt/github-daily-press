# 安装与模型设置

## 本地启动

运行项目启动脚本后，保持终端窗口打开。首次运行需要联网下载 Python 依赖，之后可以使用已有资料离线阅读。端口固定为 8765，冲突时会提示，请关闭占用程序后重试，不要改成另一个地址安装应用。

Chrome、Edge 的安装入口可能位于地址栏或“更多工具”菜单。没有出现页面安装按钮时，可以使用浏览器自己的“安装此页面为应用”。安装是独立窗口；需要真正全屏时点击页面全屏按钮，按 Esc 退出。

## 第三方模型接口

点击“模型设置”，选择云端兼容接口：

1. API URL 填服务商提供的根地址，例如 `https://api.example.com/v1`。
2. API Key 填自己的密钥。保存后重新打开设置只显示是否已配置。
3. 模型名填写服务商实际提供的标识，不能用显示昵称代替。
4. 点击测试连接，成功后保存。连接测试会发起一次小额度模型请求。

接口必须兼容 Chat Completions。本项目会检测结构化输出能力并有界降级；接口声称兼容但不支持必要参数时，会给出错误，不承诺支持所有服务商。不要在模型请求地址里填写账号密码。

## Ollama

先自行安装 Ollama 并下载适合电脑硬件的模型。在设置中选择 Ollama，地址使用 `http://127.0.0.1:11434`，模型名填写已下载的名称。不要把本机 Ollama 端口开放到公网。

Ollama 的本地接口不需要真实 API Key。模型的结构化输出能力与中文质量不同，连接通过不代表整份日报一定生成成功。

## 密钥保存方式

本地配置位于操作系统的用户配置目录，与网页公开目录分离。可使用 `GH_DAILY_CONFIG_DIR` 自定义位置。网页不会回填原始密钥；留空按设置页提示保留，删除密钥需要明确操作。

高级使用者可通过进程环境变量配置 `GH_DAILY_PROVIDER`、`GH_DAILY_BASE_URL`、`GH_DAILY_MODEL`、`GH_DAILY_API_KEY`。环境变量优先于保存的配置。`.env.example` 只说明字段，程序不会擅自读取任意 `.env` 文件。

云端配置在 GitHub Secrets 中，和本机配置分别管理。应用不会将本地密钥自动上传到 GitHub。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 点应用图标只能读旧内容 | 启动本地服务，再点击同步；查看内容日期与同步状态 |
| 提示端口占用 | 关闭另一份本项目服务或占用 8765 的程序后重试 |
| API 返回鉴权失败 | 检查密钥是否有效，以及环境变量是否覆盖了设置 |
| 模型名不存在 | 到服务商控制台或 Ollama 列表核对实际名称 |
| 无法修改设置或生成 | 设置操作需要本地服务在线，离线模式仅负责阅读 |
| 同步失败 | 检查公开仓库名、网络和远端清单；已有缓存继续保留 |
| 忘记启动命令 | 重新运行 `启动.command` 或 `启动.bat` |
