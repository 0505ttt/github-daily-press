# 阅读、安装与模型设置

## 先选自己要做的事

| 你想做什么 | 从哪里开始 |
| --- | --- |
| 看作者已经整理好的热点 | 直接打开[在线杂志](https://0505ttt.github.io/github-daily-press/)，不用安装或填写 Key |
| 把阅读放在自己的桌面 | 在 [Releases](https://github.com/0505ttt/github-daily-press/releases/latest) 查看对应平台安装包，或把网页安装为 PWA |
| 自己采编、维护自己的内容 | 运行本地应用，选择兼容接口或 Ollama；也可使用已有 AI 工具 |
| 电脑关闭后也自动采编 | 把任务部署到 GitHub Actions 等云端运行环境，见[云端自动更新](云端自动更新.md) |

在线网站展示最新已发布内容，作者完成采编并发布后才会更新。它不需要每位读者重新运行一套采编程序。

## 本地从自己的第 001 期开始

本地首次启动是**空白工作区**，不带作者的历史日报，不预填公共同步仓库，也不会自动拉取作者资料。首次成功生成自己的日报为第 001 期，后续逐期累计；正常关闭、重新启动不会清空资料或重置期号。

应用的阅读数据保存到用户数据目录，与源码和程序文件分别管理。可执行 `python -m gh_daily workspace` 查看本机工作区位置。源码仓库虽然包含公共网站历史，默认本地启动也不会把这些历史当成你的日报。

没有 API Key 也能先打开空白应用和设置。可以选择模型生成第一期，也可以让已有 AI 工具在本机工作区采编；想看作者每天整理的内容，直接打开在线杂志即可。

## 桌面安装包与 PWA

Releases 的桌面安装包面向日常启动；具体文件、平台要求及验证范围以该版本说明为准。GitHub 自动附带的 `Source code (zip)` / `Source code (tar.gz)` 是源码压缩包，不能当成已经封装运行时的安装程序。

PWA 则由浏览器安装：Chrome 或 Edge 打开[在线杂志](https://0505ttt.github.io/github-daily-press/)，选择“安装应用”或浏览器菜单的“安装此页面为应用”。安装后的独立窗口没有地址栏、标签页和书签栏；点击“全屏阅读”可进一步铺满屏幕，按 Esc 退出。

页面显示“可离线阅读”后，可阅读已缓存的版本。清除浏览器数据会移除缓存；离线时不会生成新内容。在线 PWA 恢复网络后可检查更新。

## 从源码在本机启动

这是给自行运行或修改项目的用户准备的路径。需要 Python 3.11+，桌面安装包是否已封装依赖，以对应版本说明为准。

1. 下载或克隆公开仓库，进入项目目录。
2. Mac 双击 `启动.command`；Windows 双击 `启动.bat`。
3. 首次运行联网安装依赖，之后打开固定地址 `http://127.0.0.1:8765/`，进入自己的空白工作区。
4. 保持终端窗口打开，需要停止服务时在终端按 Ctrl+C。

端口固定为 8765。冲突时会明确提示，请关闭已有本项目服务或占用程序后重试，不要改成另一个地址安装本地 PWA。

本地地址也可以安装为 PWA。**本地 PWA 图标不会启动 Python 服务**：缓存完成后可停止服务继续读；设置模型、生成或同步时，需要重新运行启动脚本。不要把这一点误认为桌面安装包的启动方式。

## 模型选择：兼容接口或 Ollama

这两种都用于“自己采编”这条路径，无需当成两套部署方案。看在线内容无需配置；打开本地空白应用也不要求先有 Key。通过已有 AI 工具采编时不必另填项目 Key，见 [AI 工具采编](AI工具采编.md)。公共在线阅读页不提供本机模型设置。

### 第三方兼容接口

本地应用点击“模型设置”，选择云端兼容接口：

1. API URL 填服务商提供的根地址，例如 `https://api.example.com/v1`。
2. API Key 填自己的密钥，保存后重新打开设置只显示是否已配置。
3. 模型名填服务商实际提供的标识，不能用显示昵称代替。
4. 设置超时与输出上限，测试连接后保存。测试会发起小额度模型请求，可能产生服务商费用。

接口必须兼容 Chat Completions。程序检测结构化输出能力并有界降级；缺少必要能力时会报告失败，不保证支持所有“兼容”服务。不要在 URL 中填写账号密码。

### 本地 Ollama

自行安装 Ollama 并下载适合电脑硬件的模型。在设置中选择 Ollama，地址使用 `http://127.0.0.1:11434`，模型名填写已经下载的名称。本地 Ollama 不需要真实 API Key，模型需支持所需的结构化输出，连接成功不等于整份日报一定能生成。

Ollama 服务和本项目采编任务都需要运行。GitHub Actions 云端的 `127.0.0.1` 指云端电脑自身，不能用这个地址连接个人电脑里的模型。不要把本机 Ollama 端口直接开放到公网。

## 密钥保存方式

本地配置存于操作系统用户配置目录，与公开网页目录分离。可通过 `GH_DAILY_CONFIG_DIR` 指定位置。网页不会回填原始密钥，留空保留或删除的行为以设置页提示为准。

高级用户可使用进程环境变量 `GH_DAILY_PROVIDER`、`GH_DAILY_BASE_URL`、`GH_DAILY_MODEL`、`GH_DAILY_API_KEY`。环境变量优先于保存配置。`.env.example` 只是字段说明，程序不会擅自读取任意 `.env` 文件。

GitHub Actions 使用仓库 Secrets，和本机配置分别管理；本地密钥不会自动上传。API URL 与 Key 不决定任务运行位置，配置了云端模型也不代表本地程序能在关机后运行。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 首次打开没有日报 | 这是自己的空白工作区。生成第一期或让已有 AI 工具采编；阅读作者历史可打开在线网址 |
| 网页还是旧一期 | 查看最新内容日期与更新状态，等待作者或自己的采编任务完成并发布 |
| 本地 PWA 只能读旧内容 | 先运行启动脚本，再同步；在线 PWA 则检查网络和更新状态 |
| 提示端口占用 | 关闭另一份本项目服务或占用 8765 的程序后重试 |
| API 鉴权失败 | 检查密钥是否有效，以及环境变量是否覆盖了设置 |
| 模型名不存在 | 到服务商控制台或 Ollama 列表核对实际名称 |
| 无法修改设置或生成 | 需要本地服务运行；公共阅读页和离线模式仅负责阅读 |
| 想同步自己的仓库 | 默认未启用同步，需要主动填写自己的或明确信任的公开仓库 |
| 同步失败 | 检查主动选择的公开仓库名、网络和远端清单，已有缓存会保留 |
| 关机后本地定时没执行 | 本机任务必须保持运行；需要关机运行时改用云端任务 |
